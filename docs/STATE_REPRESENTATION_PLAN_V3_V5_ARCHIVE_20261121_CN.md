# 状态条件 15 min 中间表示：最终执行方案（v2）

日期：2026-11-16（取代 11-15 初版）。

执行入口：[daily_state_representation_20261116_v2/README_CN.md](runs/daily_state_representation_20261116_v2/README_CN.md)。实现、预写定任务、自动门槛、两机多进程调度与运行状态均在该目录。已启动阶段一不等于已有新结果；后续阶段依门槛启用。

协议：每日 00 UTC 起报、起报后 15 h 可用；0–6 h、15 min 分辨率；55 站共享训练；2022 训练、2023 选择。

宿主模型：`ENC_neutral_E2L`（下文 R0）。R0 是从 7 种编码中按 2023 年结果挑出的，存在选择偏差，最终结论必须靠 10 seeds 和 2024 复评确认。

## 0. 依据（零训练诊断）

- **误差在小时尺度上**：目标落在整点和 :15 / :30 / :45 的 MSE 相差不超过 ±0.6%，与这些时刻本身的难度一致。线性插值没有造成小时内部的损失，所以 Δ 必须在小时尺度上组织变化，而不是逐点补细节（`runs/rmse_gap_diagnostic_20261115/phase.py`）。
- **W0 的 RMSE 劣势来自真实的大变化**：实际变化超过 0.3 时，W0 少跟了一些（3–6 h 跟上 54.6%，TF 为 55.6%）。做 5-seed 集成后差距仍在，属于结构性问题。
- **运行状态决定天气变化能否兑现**：按当前功率与变化方向分组，天气信号的误报率从 27% 到 100% 不等；把天气信号按可变化空间截断后，误报率从 56% 降到 46%（`runs/ramp_information_diagnostic_20261115/state.py`）。
- **W0 的查询中没有当前功率水平**：SEL-STATE 只有波动和差分，不含功率水平；当前功率只能经由历史记忆间接得到，TF 的输出头则直接读取当前功率。但旧协议下单站训练、10 seeds 的输出头 2×2 实验已经测过"给 W0 输出头加当前功率"：MAE +0.021%、RMSE −0.005%，没有作用。因此这里只把它当作 R3 状态 c 的一个分量，外加一个低成本对照，不当作修复手段。

## 1. 模块（只替换"天气 → 解码器查询"这一段）

- **小时潜表示**：8 个小时节点（同一次起报）经 E2L 编码，得到 z_0 … z_7；另加一阶差分 δz_m = z_{m+1} − z_m 作为输入（线性变换，不单列为机制）。
- **状态 c**（只用起点前可得的信息）：
  - 当前功率 h、可变化空间 1 − h；
  - 近 1 h 与近 6 h 的功率变化率；
  - SEL-STATE；
  - 三环区域的当前值与 1 h 变化。
- **窗口级生成器**：一个小型 Transformer 读取完整的 [z_0..7, δz, c]，为每个小时段输出 p 维参数（p = 4，表示时机与幅度）。再用固定的平滑核展开到 24 个 15 min 点，得到 Δ_k。
  - 生成器可以在小时之间重新分配变化（例如把 1 h 后的变化信号提前），这正是"误差在小时尺度"所要求的；
  - 输出层零初始化。
- **15 min 潜表示**：u_k = lerp(z)(t_k) + W·Δ_k，替代原来的天气查询分量。

## 2. 阶段一：确定性筛选（5 seeds，训练设置与 R0 完全一致）

| 编号 | 内容 | 作用 |
|---|---|---|
| R0 | 现有 `ENC_neutral_E2L`（已有结果） | 参照 |
| R0+H | R0 的输出头额外读取 [h, 1 − h]，其余不变 | 排除"收益只来自把当前功率接到输出头" |
| R1 | 先编码，再在潜空间线性插值（Δ = 0） | 插值放在哪一侧的影响 |
| R2 | 窗口级 Δ，不含 c | 表示空间细化本身 |
| R3 | 窗口级 Δ，含 c | **主候选（确定性）** |
| TF_E2L | TF_R3 的天气投影换成同样的 E2L | 同编码跨骨干对照（复盘文档列出的缺项） |

规模：5 组 × 5 = 25 次共享训练。R0 与 TF_R3 复用已有结果，不重训，以保持可比。

## 3. 阶段二：生成式（R3 至少相对 R2 双指标改善时才做）

| 编号 | 内容 |
|---|---|
| R4 | 在 §1 的每小时段 p 维参数空间里，用条件流匹配建模 p(参数 \| z, δz, c) |
| R4-noS | R4 去掉 c |
| R4-wrongS | R4 的 c 换成同月同钟点另一日的状态（训练与评价都换） |

实现要点：
- **教师**（只在训练时使用）：输入实际变化 Δy = y − h，以及插值潜表示相对起点的变化 lerp(z)(t_k) − lerp(z)(0)，输出每小时段的 p 维参数；加噪声与 KL 约束，防止直接抄目标。
- **学生路径**：训练时并行采样 4 条轨迹，用 4 条的平均功率预测计算 MAE。这样减轻逐条点预测损失对随机性的惩罚，但不能保证分布不坍缩，须另报样本离散度。
- **损失**：教师路径 MAE + 学生路径 MAE + 0.1 × 流匹配损失。
- **推理**：采样 8 次，功率预测取均值（预先写定；样本中位数另行报告，不参与选择）。
- **冒烟测试**：参数为 0 时输出等于 R1；教师不出现在推理路径；采样过程可以反传；8 个样本之间的离散度不为 0。

规模：3 组 × 5 = 15 次共享训练。R4 通过后，再做 TF + R4（5 次），检验是否依赖骨干。

## 4. 阶段三：损失复核（一次，两个骨干同时做）

- 在最终候选与 TF_R3 上各跑 MAE + 0.2·MSE（5 seeds，共 10 次）。
- 只有当"两个骨干都用这个损失时，本模型对 TF 的 MAE 与 RMSE 都胜出，且本模型自身两个指标都不劣于纯 MAE"时才采用；否则保持纯 MAE。
- **不采用**：一阶差分损失（在时机不确定时会逼出更陡、时间错位的预测，抬高 RMSE）、按实际变化幅度加权、改用 RMSE 或综合分选检查点、只对候选模型改训练流程。

## 5. 判定（预先写定）

- **主判定**：候选模型相对 R0 和同信息 TF 中较强的一个（TF_R3 或 TF_E2L），同时满足：
  - MAE 与 RMSE 都改善 ≥ 0.1%；
  - 两个指标各自过半风场改善；
  - 5 个 seed 中至少 4 个 seed 两个指标都改善；
  - 高功率 RMSE 退化 ≤ 0.1%。
- **机制判定**：
  - R3 必须同时胜过 R2 和 R0+H，才说明"状态条件"是收益来源，而不只是把当前功率接给输出头；
  - R4 必须同时胜过 R3、R4-noS、R4-wrongS，才说明"生成式"和"状态条件"都起作用；
  - 达不到就保留通过的那一级（R3 或线性插值），如实报告。
- **必报诊断**（不作为门槛）：
  - 分时效段结果；
  - 整点 / 非整点误差表（收益若只出现在非整点，视为无效）；
  - 实际变化 > 0.3 样本上的 ΔMSE 与"跟上比例"；
  - 高功率组上行、下行分开统计。

## 6. 后续

通过后依次进行：
1. 个性化，用全站统一轮数口径；
2. 扩到 10 seeds；
3. 冻结后做 2024 探索性复评，主表中 baseline 采用同样的编码、损失和个性化方式。

## 7. 不做的内容

- 非对称"可兑现门控"作为方法主体：属于门控类，新意不足；而且显式乘法结构在旧协议下已是负结果。
- 软时间偏移 τ：自适应时间读取和样本时间平移都已经是负结果；平移诊断也显示不存在系统偏移。窗口级生成器已经能做跨小时的重新分配。
- 加密验证频率、余弦退火、按 RMSE 打破平局：会改变训练协议，要做就必须对所有模型（包括重跑全部 baseline）统一实施，并预先写定。本轮不做，以保持与已有结果可比。

# v3 修订（2026-11-16，依据 `runs/daily_state_representation_20261116_v2` 已完成结果）

## A. 已知事实

阶段一（5 seeds，全部完成）：
- R0+H 相对 R0：−0.004% / −0.017%，只有 2/5 seeds 两项都改善，可以视为无效。
- R1 ≈ R0：E2L 是仿射映射，先插值后编码与先编码后插值在数学上等价。
- R2 相对 R0：+0.34% / +0.40%；R3 相对 R0：+0.27% / +0.24%；R3 相对 R2：−0.08% / −0.16%（4/5 seeds）。

R4 只有 3 个 seed 的局部结果：
- 相对 R0：MAE +1.06%，RMSE +0.69%，高功率 RMSE +0.16%；
- 相对去状态 / 错状态对照：高功率 RMSE 分别 −1.85% / −3.03%，3/3 seeds，但 MAE 也是 3/3 seeds 更差；
- 最优检查点在第 2–4 轮，之后训练目标继续下降而验证误差上升。

高功率组的方向拆分（pooled MSE）：
- R0 相对 TF_R3：上行 −6.8%，下行 +1.3%；
- R3 相对 R0：下行再 +2.2%。

缺陷在于高出力之后降不下来，不是上行过冲。

## B. 代码核查到的两个问题

1. **窗口生成器对潜天气做了非线性变换**：`Window` 把 [z, δz, c] 送入 GELU Transformer，再经 `residual_projection` 加回查询，这相当于在 E2L 之后又接了一段非线性天气支路。R2 的退化幅度（+0.34% / +0.40%）与 E2N 相对 E2L 的退化（+0.27% / +0.46%）相近。"非线性天气支路在每天仅一次起报的样本上过拟合"是目前最一致的解释，但还没有单独验证。
2. **R4 的教师路径训练了共享解码器**：`point(teacher_power)` 经 `with_parameters → decode` 回传到解码器和输出头。教师读取未来的 y，输出 7 × 4 = 28 个参数，足以编码 24 个目标值；KL 权重只有 0.001。解码器因此可以依赖教师信号走捷径，推理时教师撤掉，导致训练与推理不一致。这与"训练目标继续下降而验证误差上升"相符。

## C. 新增变体

天气部分只做线性组合，状态只决定标量系数：

- 每个小时段 s（共 7 段）内，天气相对起点的累积变化 D_k = lerp(z)(t_k) − z(起点)，这是 64 维中的线性量。
- **R3L**：u_k = lerp(z)(t_k) + β_{s(k)} · D_k，其中 β_s = 0.5·tanh(g(c, s_w, s))，g 的末层零初始化。
  - 输入 s_w 是从原始 14 通道算出的标量：10 m 与 1000 hPa 风速相对起点的变化、本小时段内的变化；
  - g 是一个两层 MLP，只读取 c、s_w 和小时段编号，不读取 z；
  - β 只缩放"预报给出的变化"，不改变天气本身的表示，也不做时间平移；
  - 小时内部的修正项不做（诊断显示小时内部不是瓶颈）。
- **R2L**：同 R3L，但 g 不读取 c（只读 s_w 和小时段编号）。
- **R3L-wrongS**：c 换成同月同钟点另一日的状态，训练与评价都换。

规模：3 组 × 5 seeds = 15 次共享训练。训练设置、选轮规则与 R0 完全一致；输出头沿用 R0（R0+H 无效，不并入）。

## D. 生成式版本（R3L 通过门槛 C 之后才做）

- **R4L**：在 7 维 β 上做条件流匹配（条件为 c、s_w），推理时 8 个样本取均值。
- **教师路径与解码器分离**：
  - 教师路径对解码器和输出头使用 detach 后的参数（`torch.func.functional_call` 传入 detach 后的权重），只更新教师；
  - 解码器只由学生路径训练。
- **教师瓶颈**：每个小时段 1 个参数（共 7 个，少于 24 个目标），KL 权重提高到 0.01，后验先验标准差 0.1。
- **对照**：R4L-noS、R4L-wrongS。
- **规模**：3 组 × 5 seeds。现有 R4 的 6 个在跑任务可以跑完存档，但不再作为候选。

## E. 门槛

- **门槛 C（R3L 进入阶段 D）**：
  - R3L 相对 R2L 与 R3L-wrongS，MAE 与 RMSE 都改善 ≥ 0.1%；
  - 且 R3L 相对 R0 两项都不差于 +0.05%。
- **主门槛**（不变）：相对 R0 和 TF_E2L / TF_R3 中较强的一个，MAE 与 RMSE 都改善 ≥ 0.1%，各自过半风场改善，至少 4/5 seeds 两项都改善，高功率 RMSE 退化 ≤ 0.1%。
- **必报诊断**：高功率组上行与下行分开报告，重点看下行；实际变化 > 0.3 样本的 ΔMSE；分时效段结果。
- **全部不通过**：如实报告"状态条件的跨分辨率表示在本数据下没有超过线性插值"，主模型保留 R0。

## F. 叙事层面的修正

- 高功率问题应写成"高出力后的下降跟踪不足"，不写"上行过冲"。限电平台段在数据中只占约 0.4%，不能作为主要论据。
- 输入特征（SEL、近邻、三环）和输出头接入当前功率都不能列为方法创新：前者属于信息输入，后者实测无效。在 R3L / R4L 通过之前，目前只有一个候选方法：**状态决定预报变化可兑现幅度的跨分辨率表示**，其中 β 是"兑现"部分，生成式是"不确定性"部分。
- R0 相对 TF_E2L 只有 1/5 seeds 两项同时改善，"骨干全面胜出"目前不成立。

# v4 修订（2026-11-16）：把"跨分辨率"与"预报兑现"拆成模型中两个独立部分

## 1. "状态决定预报变化能兑现多少"已有的正向证据

| 证据 | 结果 | 支持什么 | 不支持什么 |
|---|---|---|---|
| 历史 × 天气 2×2（旧协议，W0，2024） | 有真实历史时，天气增益约为固定历史时的 2.0 倍（MAE）、1.6 倍（RMSE），54/56 站 | 状态决定天气能被利用多少 | 不是 W0 独有 |
| 最终模型 2×2（旧协议，2024，10 seeds） | 交互项 W0 为 3.8% / 2.2%，TF 为 3.6% / 2.5% | 同上，且跨骨干成立 | 是现象，不是组件 |
| 每日新协议的交互 | W0：MAE / RMSE 交互为正，41/55、49/55 站；TF：37/55、39/55 站 | 新协议下仍然成立 | 同上 |
| 去掉 SEL-STATE 的消融 | W0 变差 +0.44% / +0.41%，TF 变差 +0.53% / +0.30% | 状态信息有用 | 属于输入信息 |
| 零训练换算诊断 | 按状态换算后，误报率 56% → 46%；Pangu 大变化检出率 25% → 71% | 状态决定可兑现的变化，机理清楚 | 不是模型结果 |
| R3 相对 R2 | −0.08% / −0.16%，4/5 seeds | 在生成器内部，状态有增益 | R3 仍输给 R0 |
| R4 相对错状态对照（3 seeds） | 高功率 RMSE −3.03% | 真实状态对高功率有用 | MAE 更差 |

结论：
- 有一致的正向证据，说明"状态决定兑现"是真实的规律；
- 但目前没有一个实现这一规律的模型组件，在同等条件下净胜过 R0 和 TF；
- 要成为创新点，必须用一个独立的兑现模块，并通过下面的检验。

## 2. 两个部分的边界

| 部分 | 回答的问题 | 作用位置 | 状态的用途 |
|---|---|---|---|
| A 跨分辨率 | 1 h 预报的变化，在 15 min 上何时发生、如何分布（含不确定性） | 生成 15 min 的预报变化表示：u_k = lerp(z)(t_k) + Δ_A | 只作为时间分配和不确定性的条件 |
| B 预报兑现 | 已对齐的预报变化，有多少能变成功率变化 | 作用在"预报相对起点的累积变化" D_k = u_k − z(起点) 上：q 的天气分量 = z(起点) + diag(1 + β_k) · D_k | 决定兑现幅度 β_k |

B 的设计：
- β_k = β(c, 预报方向, 小时段)，限幅为 0.5·tanh，末层零初始化，初始时等于 R0；
- 按预报给出的方向分为上行、下行两组（方向取自预报，部署时可得），因为已知缺陷是高出力后的下降跟踪不足；
- 只读状态 c 和少数几个风速变化标量，不读 64 维天气。

新意与风险：
- 新意不在乘性运算本身，而在两点：调制对象是"预报给出的相对起点的变化"；调制量由运行状态决定，并有错状态、去状态对照来识别。
- 文中必须承认，算子形式与门控 / FiLM 类似。

## 3. 2×2 析因与对照（5 seeds，共享训练，设置与 R0 相同）

| 编号 | A 跨分辨率 | B 兑现 | 作用 |
|---|---|---|---|
| R0 | 线性插值 | 无 | 参照（已有） |
| B | 线性插值 | 有 | B 的净效应 |
| B-noS | 线性插值 | 有，但 β 不读状态（只读风速标量和小时段） | 状态是否必要 |
| B-wrongS | 线性插值 | 有，状态换成另一日的 | 排除容量与正则化效应 |
| A | 生成（R4L，教师与解码器分离） | 无 | A 的净效应 |
| A+B | 生成 | 有 | 两部分是否叠加 |
| TF+B | TF_E2L + 同样的 B | 有 | B 是否依赖骨干 |

- 规模：确定性组（B、B-noS、B-wrongS、TF+B）共 20 次训练，先做；生成式组（A、A+B）共 10 次训练，在 B 有结果后做。
- R4L 的教师修正（与解码器分离、7 参数瓶颈、KL 0.01）见 v3 第 D 节。

## 4. 判定（预先写定）

- **B 成立（创新点二）**：
  - B 相对 R0、B-noS、B-wrongS，MAE 与 RMSE 都改善 ≥ 0.1%；
  - 相对 R0 时，各自过半风场改善，至少 4/5 seeds 两项都改善；
  - 高功率 RMSE 退化 ≤ 0.1%，下行段单独报告。
  - TF+B 相对 TF_E2L 若也通过，写成"可迁移的兑现模块"。
- **A 成立（创新点一）**：
  - A 相对 R0 两项都改善 ≥ 0.1%；
  - 且 A+B 相对 B 两项都改善 ≥ 0.1%，即在已有兑现模块的基础上仍有增益。
- **主门槛**：最终模型（A+B，或只通过一部分时用那一部分）相对 R0 和较强的同信息 TF，满足原主门槛。
- **只通过一部分**：只写通过的那一个创新点，另一个如实报告为负结果。
