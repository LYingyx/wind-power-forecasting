# 中文短稿全文精读与精修建议

本文档针对当前中文短稿进行全文精读审阅，目标不是继续大幅改结构，而是在现有主线已经收敛到“运行状态约束”的基础上，进一步提高叙述精度、实验解释稳健性和审稿可接受度。

审阅范围：

- `manuscript_zh_short.tex`
- `sections_short/introduction_zh.tex`
- `sections_short/related_work_zh.tex`
- `sections_short/problem_zh.tex`
- `sections_short/method_zh.tex`
- `sections_short/experiments_zh.tex`
- `sections_short/conclusion_zh.tex`

当前总体判断：

论文主线已经基本正确：未来气象是日内预测主驱动，预测起点前真实功率状态提供运行状态约束，模型把该约束写入气象读取过程，实验通过 Weather-only、Random power、Zero power、Basic GCN 等对比验证真实功率状态的贡献。

仍建议优化的核心问题有三类：

1. 个别句子仍有轻微“拉踩”或泛化判断风险。
2. 术语体系还不够统一，中文与英文术语混用略多。
3. 实验解释可以更克制，让结果自己支撑“运行状态约束”主线。

## 优先级总览

### P0：建议优先改

- 引言中“若将历史功率与未来气象简单拼接，又难以体现...”仍有轻微拉踩风险。
- 摘要中“现有方法通常以未来气象预报为主要输入”略宽泛，“预测日前后”略口语且不够精确。
- 相关工作中“讨论仍有限”“仍需要专门建模”可以更中性。
- 实验中“最强”“显著”“强约束”等词可以减少，避免超出表格证据。
- 结论中“不替代未来气象主驱动”语义略拧巴，建议改成“在未来气象主导下”。

### P1：建议随后改

- 标题可以考虑加入“日内预测”，与摘要和正文统一。
- 方法章节英文术语过密，建议首次出现时采用“中文名（英文名）”，后文再用简称。
- `memory`、`token`、`future queries`、`query`、`horizon`、`lead time` 应建立统一译法，不要同一概念多种写法。
- 表格标题建议标明“归一化指标”，避免读者误解 MAE/RMSE 的量纲。
- 逐预测步分析可以减少一次重复解释，把机制说明集中到图后段。

### P2：可视版面和投稿前检查

- 图注中英文术语较多，可适度中文化。
- 参考文献年份较新，正式投稿前建议逐条核对 DOI、卷期和题名。
- `COMPILE.md` 中中文编译路径仍是旧目录，后续交付前建议同步更新。

## P0 详细建议

### 1. 摘要：再收紧，减少泛化和含混表达

位置：

- `manuscript_zh_short.tex:89`

当前摘要整体已经比前版自然，但仍有两点可优化。

问题一：

```tex

```

这句话不是错，但“现有方法通常”范围较大，容易让审稿人期待一套全面的 existing methods 论证。本文实验真正支撑的是“在气象驱动预测框架下，加入运行状态约束有效”，不必对全部现有方法做概括。

建议改为：

```tex

```

这样把对象限定为“气象驱动模型”，更精确。

问题二：

```tex

```

“预测日前后”略口语，也不够学术。它表达的是“预测日前气象上下文 + 预测日内未来气象”。用户已经明确不希望写 16 h 细节，因此建议用概括但准确的表达。

建议改为：

```tex

```

问题三：

```tex

```

全文更多使用“状态失配”“状态约束”，这里建议统一成“状态适配能力”，更贴合前文问题定义。

建议改为：

```tex
提高区域风电集群预测的状态适配能力
```

建议摘要替换稿：

```tex
区域风电集群日内出力预测是电力调度、备用容量配置和新能源消纳的重要基础。气象驱动的预测模型通常依赖未来气象预报刻画预测日内的风场演化，但同一气象形势下的实际出力还会受到预测起点前场站出力水平、短时惯性和多场站同步变化的影响；如果模型只关注未来气象，容易在预测初期产生与真实运行状态不一致的偏差。为此，本文提出一种运行状态约束的气象-功率融合网络。该方法利用预测日前气象上下文和预测日内未来气象提取气象驱动表示，并将预测起点前可用的场站级实测功率编码为运行状态表示；随后在解码阶段将运行状态融入气象驱动预测过程，使模型在利用未来风场变化的同时保持对当前场群状态的感知。在吉林区域 58 个风电场站数据上的实验表明，所提方法在日内聚合功率预测中取得 0.0767 的 MAE、0.1041 的 RMSE 和 0.8330 的 \(R^2\)，相比最优基线 MAE 降低约 4.1\%。逐预测步分析显示，预测初期收益最明显，首小时 MAE 降低约 42.4\%。结果说明，预测起点前的真实功率状态能够有效约束气象到功率的映射，提高区域风电集群预测的状态适配能力。
```

说明：

这版没有增加细节，不引入 16 h，不拉踩其他方法，同时把“运行状态约束”放在摘要中心。
