# “不是……而是……”句式改写草案

目标：去掉全文中“不是/并非/而是/而不是/并不追求……”这类否定-转折式表达，改为正向定义、机制说明或结果归因。正文先改中文，英文随后同步删除对应的 not ... but、rather than、instead 等表达。

## 6. 英文同步原则

英文版对应删除以下表达：

- is not ... but ...
- does not ... rather ...
- rather than ...
- instead / instead of 用于强转折的地方
- neither ... nor ... but ...

同步改写方向：

- 用正向定义替代否定对照，例如 “The framework moves fusion to the memory level.”
- 用结果归因替代 “not from A but from B”，例如 “The improvement is attributed to the observed power state before the target window.”
- 用方法定位替代 “neither A nor B but C”，例如 “These findings position the method as an operating-state-constrained weather-power fusion model.”
