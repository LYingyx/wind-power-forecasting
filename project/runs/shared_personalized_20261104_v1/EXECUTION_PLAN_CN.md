# 共享预训练与单站个性化：执行修订

2026-11-04。原方案值得进行前两阶段验证；旧协议下的共享收益不能预设在业务协议下成立。

## 冻结的调整

- 样本沿用业务 Pangu 年龄12–23.75h的缓存；2022训练、2023选择，2023剔除11月及既有边界样本。2024尚未纳入本轮读取或训练，将来只能称探索性复评。
- 质量规则先于新模型训练写入 `QC_RULES.json`。仅使用2022、2023功率；55站保留。龙湖（1043056）因归一化功率q99从0.2214升至0.9213触发跨年幅值变化规则而删除。这是容量/数据一致性警报，不等于确定了设备或业务原因。
- 删除站不进入任何近邻和距离环输入；所有邻域按55站重新计算，延迟15min。三环仍为 <20、20–60、60–150km。
- TF BASE、TF R3、W0 R3、TiDE R3、TFT R3各接受同样8配置×2调参seeds；所有R3模型的输入信息相同，含静态描述和8维可学习站点嵌入。TiDE/TFT明确为现有代码中的模型家族适配实现，不宣称官方原版。
- 共享B0采用本站历史TCN与时效注意力，不额外读全区域功率。它是本轮统一实现，不是旧协议含全局历史分支的ForcedEvolution原模型。旧5.1%结果只作为假设依据。
- 2022参考轨迹采用4个季度分块交叉拟合，块间隔离12h。每折另从其余2022数据留出21天用于早停，不用该折待预测标签选检查点。完整2022 B0用于2023推理。防止训练输入用到拟合过自身目标的参考轨迹。
- M2配套历史摘要与轨迹一起错配的M4H；TF上增设中性适配器和错配适配器，与真实轨迹条件比较参数增量。
- 所有检查点只按等风场权重的2023 MAE选择，RMSE从同一检查点报告。OOF B0例外：按内部2022验证块选择。输出不裁剪。
- HPO每次至多30epochs/patience6，正式共享训练至多80epochs/patience10；每次逻辑batch512，OOM时仅减小microbatch并累积梯度，不改变逻辑batch。

## 判定与后续

先报告W0 R3与TF R3的共享结果。若基础W0未超过TF，仍执行机制筛选，这是原方案第一判定点后的分支。

只有M1或M2相对W0基础、匹配错配对照、以及最强同输入基线均满足双指标至少0.1%改善、各自过半站改善，且高功率组RMSE退化不超过0.1%，才标记可进入个性化。最强同输入基线按2023 MAE在TF/TiDE/TFT中选择；所有比较同时报告RMSE和站点区间。

队列在前两阶段结束后生成 `analysis/GATES.json` 和结果表，不提前发出约2800次微调或2024任务。通过后才根据实际胜出的骨干、配置与机制具体化P1–P4；P3的物理分工解释需要对照结果支持。

旧独立模型用56站邻域，不能直接作为55站新区域输入下的公平共享对照。旧结果仅作背景；同输入独立重训、完整56站敏感性分析归入后续机制复验，不据旧表宣称共享增益。

## 调度

两台V100与4090本机均部署持久调度。按最新“4090有空的位置”的授权，本机监听0–7卡；有其他活跃计算时等待。每卡可多进程，至少保留4GiB或20%显存，最多6个本轮进程，并通过每25步耗时标定，单进程明显变慢则让本轮进程保存断点、退出并重排。其他用户进程不终止、不迁移、不改设置。

显存闲置不代表算力闲置。2026-11-04本轮部署期间4090已有其他用户新任务，因此允许本机保持等待。启动后以实际主机、PID、训练步数核验，不把仅存在队列当作已训练。
