# 历史气象代理诊断（2026-11-06）

只用 CPU 读取 `shared_personalized_20261104_v1/data`（55 站）缓存，2022 拟合、2023 评价，不读 2024，不训练神经网络。

运行：`../../.runtime/chronos/bin/python -I persist.py`（其余脚本同理）。

- 基础模型：逐站 2022 风速（1000 hPa）–功率 30 分箱曲线；`persist2.py`/`horizon.py` 另加当前功率的线性组合。只用整点起报样本。
- `persist.py`：纯天气曲线残差的日均值自相关，以及 3/7/14/30 天均匀滚动偏差校正。
- `persist2.py`：4 h 时效、"当前功率 + 曲线"基础上的 7/14/30/60 天均匀滚动偏差，以及 30 天按曲线三分位分档的滚动偏差。
- `lag.py`：加入上一期次（年龄 24–36 h）预报的水平与修正量。
- `horizon.py`：30 天分档滚动偏差在 1/2/4/6 h 的效果（初版，按"前几天"取窗口，凌晨起报的样本存在不足 1% 的同日前瞻）。
- `horizon_strict.py`：严格因果版本，只用目标时刻 ≤ 起报 − 15 min 且起报 ≥ t − D 天的残差。**以此为准。**

主要结果（55 站等权平均；MAE / RMSE 相对变化，负为改善）：
