距离配对在所有圈非空的共同支持41站上比较，其他15站保留结果但不用于距离机制对比。每站k=min(4,近/中/远圈站数)，只根据地理/装机容量和预定seed取子集，不用2023功率选邻站。所有MATCH与FULL都保留同一个N3基础通路；测的是额外区域摘要的条件增量，不是完全隔离距离圈。匹配不保证容量完全相同，差异在MATCHING_AUDIT.json中保留。MATCH子集随预定seed变化，因此其复验同时覆盖子集抽样和优化随机性，不称纯优化随机性复验。

门控采用同一骨干两次前向：本站路径p0，区域路径p1，输出p0+g(p1−p0)。g∈[0,1]，不截断预测功率；局部路径共同训练，并非锁死既有N0。两次前向共享同一个dropout随机样本，避免将dropout差异当区域增量。G_FREE取g=1；LEAD用正时间常数的指数衰减；STATE用本站功率/变化、区域功率/变化/离散度/差值、NWP目标风速/变化预测幅度；联合版同时使用状态幅度与样本时间常数。状态特征全部在起报时可得，区域最新观测为t0−15min。没有使用未来实测下降标签。G_FREE与已训练RAW推理一致性、零区域分支训练态无伪增量均已检查。

验收同时报告：整体与逐15min时效、当前功率、区域趋势、实际后续变化×NWP变化、季节/稳定度等。高功率按起报CF≥0.7，不等于确认额定平台；后续变化只能作诊断。相对N0、N3、RAW三种参照都保留。

门控/简化的扩种子门槛：整体对N0/N3两指标均改善≥0.1%，各至少29站改善；整体和两个短时效段对RAW退化≤0.1%；高功率全部及3–6h的RMSE相对N0/N3退化≤0.1%；优于自身C2；另须整体双指标或高功率3–6h双指标相对RAW改善≥0.1%。某骨干门控通过时，四门控及其C2一起扩种子，避免只复验赢家而丢失组件比较。MEAN_DELTA按骨干独立扩展。

删近圈按整体/高功率相对RAW点估计无明显损失触发两种删法一起复验，并单独报告非劣区间；点估计通过不等于已证明等价。匹配距离或FULL/MATCH任一预定双指标对比有≥0.1%且过半站改善时，全部MATCH/FULL一起扩种子。这些是机制诊断复验，不自动升级为主模型。十种子仍是2023选择年证据，不等于跨年复评。详见冻结JSON。
