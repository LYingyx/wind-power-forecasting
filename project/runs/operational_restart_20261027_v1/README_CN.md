# 业务时延下的基线与机制重建

盘古初始化为北京时间08/20时，12小时后可用于功率预测；每个样本整条6小时天气轨迹固定使用起报时已经可用的一期预报。功率源为北京时间，盘古文件名为UTC；缓存统一Unix秒，不再重复加8小时。预报年龄12–23.75小时，最晚需要第30小时的天气端点。

2022训练、2023选择，56站×2种子（42/43）。本轮不评价2024。已重建的测试集剔除了2024年11月及可能引用问题起报周期的边界样本。旧训练结果不能视为此协议的结果。

训练配置：B0；W0与TF*分别使用SEL、SEL+N3、SEL+R3_RAW、SEL+异日错配R3_RAW、SEL+预报年龄；W0+SEL增加H0W1/H1W0/H0W0，合计14配置、1568次训练。持续法不需要训练。TF*零初始化输出层，学习率2e-4，dropout0.05。全部从头训练，天气/E2C/SEL标准化仅使用新训练数据。

N3为150km内8近邻的容量加权历史汇总；R3_RAW加0–20、20–60、60–150km三圈的均值、站间标准差、1小时变化和存在标记，排除本站。邻站观测截至起报前15分钟。错配将所有邻站整体换为2022同月、同北京时间、至少相隔48小时的一天，验证期也只从训练年取供体。

历史×天气2×2同步处理SEL派生特征。四格都保留实际起报功率作为持续法锚点；固定历史意味着固定历史编码器输入与STATE特征，固定天气意味着固定天气输入和天气派生SEL均值。因此检验的是给定当前功率后的历史上下文×天气交互，不能声称完全移除了历史或证明因果作用。

P1先做单调风速功率映射和固定岭回归诊断。映射只拟合2022；训练残差对观测所属月份留出并添加24小时缓冲。使用当前已可用的同一预报周期回看过去，残差统一为实测减映射功率。它包含气象、功率曲线、运行状态等误差，不等同于纯NWP误差；ERA5初始化不能保证功率误差为零。

P1门槛：2023条件岭回归在本站历史、未来映射天气和预报年龄之外，MAE/RMSE均改善≥0.1%，各>28站改善，过去到未来映射误差平均相关的站间中位数≥0.05，才启动本站残差及错配训练；区域残差还须优于本站残差及原始三圈对照。诊断另保留含原始三圈条件的更严格版本，避免把相关性误写为独立信息的证明。年龄输入仍保留，它与业务时刻相关，不单独识别预报年龄的因果效应。

训练验收以同一个MAE最优检查点报告MAE/RMSE，先站内平均种子，再56站等权平均。两指标均改善≥0.1%、各>28站改善、高功率（当前功率≥0.7）RMSE退化≤0.5%。正向变体及配套对照自动补至10种子；2×2满足双指标正交互且各>28站同号时四格一并补齐。2023结果仍有选择偏差，风场bootstrap区间未消除空间相关。

三机调度：仅本机、v1006001、v1006002。每卡最多12进程是安全上限，实际由显存、算力、CPU/RAM和实测epoch效率决定；保留至少4GiB或20%显存。新增并发需通过效率观测，epoch耗时连续超过同任务较低并发的1.5倍则让本轮任务保存断点并退出。两台V100允许共享算力；本机遇其他任务活跃或余量不足则等待/释放本轮进程，不终止其他任务。

`STATUS.json`为总体状态，`schedulers/`为每机逐卡准入和活跃进程，`operations/REMOTE_STATUS.json`为远端租约与回收，`analysis/REPORT_CN.md`与`REPORT.json`自动更新。远端选中权重回收后核对SHA256；失败任务单列，不能以无进程或旧SUCCESS冒充完成。完成审计写入`operations/COMPLETE_AUDIT.json`。
