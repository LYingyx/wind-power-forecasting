# 已完成实验的正反馈、负反馈与下一步判别

本分析冻结于 2026-11-16 13:47 左右。第一阶段五种子完整；R4 三组仅 seed 42、43、45 完整，44、46 仍在运行。R0 指 ENC_neutral_E2L；本文 R3 指新增状态条件窗口生成器，不是旧实验名称中表示输入配置的 R3。

所有百分比都是相对变化，负数为改善；总体表为风场等权 MAE/RMSE，分组诊断为 pooled MSE，二者不可混算。2023 同时用于选模和报告，E2L 又从七种编码中选出，以下属于研究反馈，不能冒充独立测试结论。精确数值、同种子配对、留一 seed 敏感性和来源哈希见 [机器可读证据](LEARNINGS_EVIDENCE_20261116.json)。

## 1. 输出头补当前功率，不能解决主要差距

R0+H 相对 R0：MAE −0.0041%、RMSE −0.0170%、高功率 RMSE −0.0444%，只有 2/5 seeds 双指标同时改善，远低于预定主门槛。

新协议复验支持“单独加这条输出头连接收益很小”，不支持“模型缺少当前功率输入，所以补上即可解决”。当前功率原本已作为持久性锚点和历史输入存在。这个结果不能推出当前功率或状态本身没有价值。

## 2. 状态缓解了窗口生成器的退化，但整个模块仍未获净收益

| 候选 / 参照 | ΔMAE | ΔRMSE | Δ高功率 RMSE |
|---|---:|---:|---:|
| R2 / R0 | +0.3423% | +0.3997% | +0.6380% |
| R3 / R2 | −0.0765% | −0.1556% | −0.1889% |
| R3 / R0 | +0.2656% | +0.2435% | +0.4478% |
| R3 / R0+H | +0.2697% | +0.2606% | +0.4924% |

R3 对 R2：4/5 seeds 双指标改善，MAE/RMSE 分别在 36/55、39/55 站改善，是值得保留的条件增益。但 R3 对 R0 没有一个 seed 双指标同时胜出，不能据内部消融胜出就说完整方法有效。当前实现里，窗口生成器引入的损失大于状态带来的收益。

R1 对 R0 的 MAE/RMSE 为 +0.0161%/+0.0159%。E2L 是仿射映射，先插值再编码与先编码再插值数学等价；R1 只支持数值对照，不支持“搬到潜空间插值本身构成有效机制”。有限精度下训练轨迹可有微小差异。

这否定的是当前已实现的 7 段 × 4 参数生成器及其训练方式的净收益，不是对所有状态条件表示的普遍否定。

## 3. 同编码 TF 对照收窄了骨干优势，也暴露了随机种子敏感性

TF_E2L 对 TF_R3：MAE −0.3005%、RMSE −0.0582%、高功率 RMSE +0.2801%。编码更换的收益可出现在 TF，不能归为本骨干独有，更不应将编码列作机制贡献。

R0 对 TF_E2L：MAE −0.1568%、RMSE −0.1578%、高功率 RMSE −0.1268%；改善站数依次为 33、30、36/55。这是同编码下仍存在小幅平均优势的正反馈。但只有 1/5 seeds 双指标同时改善，未通过稳定性门槛。

全部五次留一 seed 敏感性检查中，去掉 seed 42 时 MAE 变为 +0.0849%、RMSE 为 −0.0226%；其他四次仍双指标平均改善。说明优势对 seed 42 敏感。这个诊断不意味着应该删除种子或重算“正式成绩”。10 seeds 可以检查随机性，但不能消除在 2023 上筛选 E2L 的偏差。

## 4. 高功率误差需拆成上行和下行，当前更值得追查下行

高功率定义为起点功率 ≥0.75，方向由未来真实功率相对起点的变化确定。这些未来标签只用于事后诊断，不能直接作为部署时可用的门控标签。

| pooled MSE 比较 | 高功率后上行 | 高功率后下行 |
|---|---:|---:|
| R0 / TF_R3 | −6.8259% | +1.2838% |
| R3 / R0 | −2.4282% | +2.2118% |
| R3 / TF_R3 | −9.0883% | +3.5240% |

下行样本单元数约为上行的 2.52 倍。高功率下降段的变化捕获比例：TF_R3 67.64%、R0 65.14%、R3 63.51%。这个比例是预测变化沿真实方向的总幅度除以真实总幅度，不是事件命中率。

新增状态生成器进一步改善上行，却恶化更常见的下降段；当前证据指向“高出力之后降不下来”的跟踪不足。不能只凭高功率总指标推断为上行过冲，也不能据此直接声称已找到限功率、停机或天气相位误差等物理原因。

## 5. 小时内插值不是当前已被证实的主要瓶颈

R0 对 TF_R3 在目标整点、:15、:30、:45 的 pooled MSE 改善分别为 0.432%、0.442%、0.464%、0.466%，没有出现非整点普遍明显变坏的模式。这削弱了“线性插值导致小时内损失，所以细化到 15 min 就能修复”的解释，但不等价于证明插值完全无影响。

真实变化幅度 >0.3 的子集上，R0 对 TF_R3 的 MSE 在 0–1 h 为 −1.489%，1–3 h 为 +0.909%，3–6 h 为 +0.285%。R3 对 R0 在这三个时段又分别增加 1.313%、0.371%、0.196%。因此当前生成器没有实现预期的大变化收益，后续诊断更应关注 1–6 h 变化幅度与时机的关系。

按未来真实大变化筛选的子集，本身会强调历史上难以预见的事件；捕获比例低不能单独证明这些变化在起点可预测，也不能推出只需加大输出幅度即可。

## 6. R4 三种子局部结果：状态有局部价值，生成式方案整体尚不乐观

以下比较全部限定到相同 seeds 42、43、45，没有用三种子候选对五种子基线，也没有用它们启用下一阶段。

| 候选 / 参照 | ΔMAE | ΔRMSE | Δ高功率 RMSE |
|---|---:|---:|---:|
| R4 / R0 | +1.0554% | +0.6948% | +0.1636% |
| R4 / R3 | +0.5496% | +0.3787% | −0.0846% |
| R4 / TF_R3 | +0.4905% | +0.4413% | +0.1811% |
| R4 / TF_E2L | +0.6482% | +0.3505% | −0.1269% |
| R4 / R4-noS | +0.3099% | −0.1933% | −1.8532% |
| R4 / R4-wrongS | +0.2325% | −0.1472% | −3.0266% |

R4 相对 R0、R3、两个 TF，在这三个种子上 MAE 均未胜出。真实状态相对去状态和错状态的高功率 RMSE 在 3/3 seeds 都改善，是值得保留的局部正反馈；但 MAE 同样在 3/3 seeds 更差，因此不满足预写定机制成立条件。

R4 的平均样本标准差为 0.0190–0.0203 容量因子，标准差 >1e−6 的比例为 100%。目前不是所有输出样本都完全相同的退化。样本有离散度不等于分布经过校准，也不保证采样均值预测更准确，不能把失败都归因于“采样坍缩”。

这九项生成式任务在第 2–4 轮取得最佳验证 MAE，第 12–14 轮早停，耗时约 6.6–8.3 h；组合训练目标仍持续下降而验证误差增大。这提示泛化或目标不一致值得检查，尚不能区分训练过拟合、教师目标与学生目标不匹配等原因。它们比本轮确定性对照耗时明显更多，目前没有相应精度收益。

## 7. 此前新协议完整矩阵仍有可保留的工程结论

详见 [2571 项重训审查](../../../DAILY_PROTOCOL_RESULTS_REVIEW_20261115_CN.md)。这里引用的是旧一轮的新业务协议结果，不能把默认 E2C 的结果直接挪作当前 E2L 成绩。

- 共享训练仍逐风场输出，符合单风场预测任务。默认 W0 的逐站独立 R3 对共享 R3，MAE/RMSE +2.524%/+1.748%，TF 同方向；当前预算下共享更合适，但两种训练方式优化器总更新数不同，不能外推为独立训练必然较差。
- 区域统计和历史状态信息有价值：W0 去掉三环区域统计，MAE/RMSE +0.682%/+0.625%；去掉状态特征 +0.437%/+0.406%。TF 上也有效，所以这是信息价值证据，不能全部计为本模型结构贡献。
- 完全移除天气及天气派生输入使两骨干 MAE 恶化约 19%，不支持“这个超短期任务天气没有用”。这仍不证明新增复杂天气生成器有效。
- 当前没有严格目标风场留出的新协议迁移验证，不能把已见风场微调写成新风场迁移优势。

## 对后续路线的约束

继续完成冻结的 R4 五种子和公平损失复核；不要以三个种子的局部结果提前宣告成功或失败。若完整结果仍不通过，就否决当前窗口生成器/流匹配路线的优势叙事，不靠追加模块或更换指标保住故事。

保留 R0 与同编码 TF_E2L 作为最直接的骨干比较，编码只作实现选项。把高功率下行、1–6 h 真实大变化和随机种子敏感性作为下一轮问题定位依据；新增机制必须在完整模型上取得净收益，同时胜过简单对照，并通过预写定的稳定性和高功率约束。未来若改变训练损失或选模协议，需对匹配 baseline 同步实施，当前矩阵不改。
