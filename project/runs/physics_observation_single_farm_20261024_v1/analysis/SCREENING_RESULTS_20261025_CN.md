## 实际结构与缩写

W0：NEUTRAL_LAST活跃骨干，包含历史编码器、E2C固定点天气编码、条件适配器、历史交叉注意力解码器和末次观测残差输出。TF：64维Transformer未来协变量基线，历史编码器、天气查询解码器及末次观测残差头。两者按站独立训练。新增普通输入均经零初始化线性投影加到64维查询。

| 变体 | 实际输入/结构 |
| --- | --- |
| BASE | 原固定点天气/历史功率骨干，不增加输入或结构 |
| CAP | 仅已有天气、末值和时效的额外零初始化线性投影，额外容量对照 |
| CAL | 目标当地时刻和年周期四个sin/cos特征 |
| REF | 起报天气代理14通道及历史/未来发布年龄2通道 |
| DELTA | REF + 目标天气减起报天气；与REF比较变化量重参数化 |
| DENS | DEM干空气压强修正后的密度与风能代理3维 |
| STAB | 位温梯度/切变/Ri/有效掩码/中性高度风代理5维 |
| DYN | 925hPa地转风/非地转差/温度平流/气压倾向/风速倾向7维 |
| STATE | 仅历史功率生成的波动、趋势、平台持续时间7维 |
| CYCLE | 同有效时间相邻发布周期天气差14维及有效掩码 |
| ALL | CAL+REF+DELTA+DENS+STAB+DYN+STATE+CYCLE组合，不预称主方法 |
| HIST | 六个历史天气节点、对应时差及发布年龄的查询投影 |
| SHIFT_ZERO | HIST + 恒零时间位移；保留相同位移网络，参数不活跃须注明 |
| SHIFT_FIXED | HIST + 相同网络读取训练期平均状态，学习全站固定时间位移 |
| SHIFT_SAMPLE | HIST + 实际历史功率/天气估计每样本[-1,1]h位移 |
| PC_INPUT | REF+DENS仅输入对照 |
| CURVE_FREE | PC_INPUT + 可正负分段响应曲线、衰减偏差、零初始化残差门控 |
| CURVE_BIAS | PC_INPUT + 单调饱和分段响应曲线、衰减偏差、零初始化残差门控；不截断CF |
| NEIGH_GENERIC | CAL + 8个最近邻站/150km掩码的历史功率注意力，含null token |
| NEIGH_ADVECT | NEIGH_GENERIC同参数同信息，另加固定方向与传播时间软先验 |

DENS的三个输入准确为：ρ/1.225、(ρ/1.225)^(1/3)×10m风速/10、ρ×10m风速³/1000。它同时引入密度、风速重参数化和风能代理；当前收益不能单独归因于空气密度。容量对照为同形状投影输入既有特征的确定性展开，未单独控制v、v³或恒定密度。

MAE/MSE/MIX是训练损失；MIX=0.5 MAE+0.5 MSE/0.1。所有损失均按验证MAE耐心10早停。表内默认MAE选权重，RMSE选权重的完整对照在CSV中，不能混为同一协议。

## 当前可支持的表述与下一步

可保留的研究主线是“单风场历史状态与天气信息表示的受控增强”。当前新增证据优先支持DENS特征组合与ALL组合的验证收益，不支持预先把自适应空间提取、样本时间位移或上游传播定为核心贡献。DENS并不等于单独密度修正，ALL也不等于每项物理特征均有效。

后续应先冻结具体选择与比较清单，再做跨年回顾性复评。若继续归因，最直接的缺口是：DENS中密度、原风速/风速³、密度校正风速的分拆，以及ALL逐项去除；ALL相对DENS的直接对照已经列出。复评仍应保留同输入、同损失、同选权重的TF比较。容量结果只覆盖6站。邻站扩展需同时审查原值干预与延迟结果，不把胜场多或某个seed改善当作显著机制。

本报告完成2023筛选结果的汇总与初步解释，后续归因、跨年复评和论文更新仍需据此确定具体方案。
