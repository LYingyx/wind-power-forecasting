# 共享预训练后逐站微调：独立验证

本轮回答共享参数是否适合每个场站，以及微调是否改善 MAE 与 RMSE。参考轨迹机制在上一轮未通过；本轮使用 W0_R3 和 TF_R3 原始共享模型，不能把微调收益归于参考轨迹。

## 设计

- 同一 55 站集合与邻站输入；2022 训练、2023 选择（剔除 11 月）；2024 不参与。
- 使用上一轮经过核验的共享最优检查点，seeds 42–46；两骨干都包含 SEL 与区域实况。
- P0：共享模型直接预测；复用现有 550 条逐站、逐 seed 指标，无需训练。
- P1：每站全参数微调。
- P2：每站仅输出 MLP 与本站嵌入微调，其余参数冻结。其他站点嵌入行保持不变。
- P1/P2 共 2 骨干 × 2 方式 × 55 站 × 5 seeds = 1,100 次微调。
- 两骨干统一 AdamW，学习率 2e-5，batch 512，最多 30 轮，6 轮 patience。损失为 MAE，归一化参数完全复用 2022 统计。
- 微调第 0 轮作为候选，按本站 2023 MAE 选择；同一检查点评价 RMSE。必须报告选中第 0 轮的数量，不能把选择集收益当成独立验证。
- 每个骨干按全站 2023 MAE 选择统一微调方式；不按站点挑选不同方式以美化表格。

## 比较

1. P1/P2 对各自 P0：微调有没有收益。
2. W0 对 TF，同一种微调方式：是否双指标优于同设定基线。
3. 各自按相同准则选择的最优方式之间比较。
4. 报告每站 MAE/RMSE、每 seed、0–1/1–3/3–6 h、高功率 RMSE、选中轮数与第 0 轮占比。

验收仍为相对改善 MAE 与 RMSE 各至少 0.1%，两个指标分别严格过半场站改善，高功率 RMSE 退化不超过 0.1%。完整 5 seeds 前不宣布过关。2024、P3、LoRA 和 10 seeds 不自动触发，需要依据本轮结果制定下一步。

本轮没有同协议从零训练单站模型，不能用旧独立训练数值证明共享预训练优势；本轮能直接回答的是“共享模型是否受益于逐站微调”。

## 执行

三台机器部署同一份冻结代码、资产与源检查点；输入等价、冻结参数、目标嵌入行、CPU/GPU 一致性和断点续训均检查。4090 利用空余显存和计算，多进程；V100 自适应补位。保留显存/系统内存/磁盘额度；不终止其他用户进程，按自身训练速度降低过高并发。数据和模型输出位于 SSD3，逐站特征缓存只复用共享输入以减少重复计算。
