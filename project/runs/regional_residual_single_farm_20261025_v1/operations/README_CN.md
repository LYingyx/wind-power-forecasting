# 运行与续接

本轮 regional_residual_single_farm_20261025_v1，只允许当前 4090、v1006001、v1006002；P60002/P60003 禁用。6001、4090 保守避让外部计算，6002 按用户授权共享余量。每卡动态测量计算/显存，保留至少 4 GiB 或 20%；每轮最多加一个进程，20 秒预热，最多 12 进程/卡并非固定并发数。

STATUS.json 由中央统计；operations/REMOTE_STATUS.json 和 schedulers/*.json 显示逐机逐卡活动进程、资源和等待原因。仅 SUCCESS 核验成功算完成。CPU 最多 4 个低优先级单线程任务，负载达到核数 75% 或内存预留不足时不新开任务；ARX 和旧权重重放共用此池。GPU 队列只领神经训练。

remote_controller 按文件锁分配租约；网络断开保留租约，避免重复训练。先回传核验 spec 和选中权重哈希，再删除远端重复权重。每项神经训练最多 2 个选中权重，成功删除 latest；ARX 每站 1 个紧凑系数文件；不保存逐样本预测或注意力数组。已完成的上一轮队列不重启。

bootstrap 在资源允许时执行真实数据、训练后权重的数值兼容检查，再进入 scheduler。GLOBAL_COMPLETE 后退出，避免空队列残留。科学文件冻结后如发现问题，必须记录修订和受影响任务，不能静默改源码或成功标记。

finalize_when_done 等待全部 2,968 项成功，审计来源、所选权重、文件哈希后运行 analyze_round.py，输出分组、逐时效、效应量及主次检验判断。它不开放 2024。保留原 B1 冻结，另以 B1_DEFERRED_REGIONAL_RESIDUAL.json 记录继续延期。
