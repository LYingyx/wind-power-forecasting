# 锚点衰减方案审查：已有证据、反证与改进实验

时间：2026-10-28T22:09:42.913107+08:00。使用已有56站×10 seeds的检查点指标、场景充分统计量与数据时间元信息，没有新训练。

## 结论

通用基线主表判断成立；“远时效缺陷由硬锚点引起”目前证据不足，建议先定位读出层、季节泛化和区域输入与骨干的交互，再决定是否设计状态衰减模块。原建议的第0步部分无需推理重放，已有逐时效MAE/RMSE、分组SSE与逐日充分统计量足够完成。

## 1. 2023没有复现逐时效反转

变化均指W0_R3_RAW相对TF_R3_RAW；负值为W0更好。

|年份|全时效MAE|全时效RMSE|6h MAE|6h RMSE|
|---|---:|---:|---:|---:|
|2023|-1.052%|-0.397%|-0.351%|-0.047%|
|2024|-0.421%|0.335%|0.737%|1.035%|

2023的24个时效点MAE和RMSE均为W0更好。6h RMSE优势虽仅0.047%，但不存在2024的晚时效反转。因此“2023先复现同样远时效缺陷，再训练A1”的门槛，按原先描述没有通过。2024也不是每一个0–2h点都W0更好：2h点RMSE为+0.146%，3.25h以后则持续为正。

然而季节弱势有部分跨年一致性：2023冬季/夏季RMSE分别+1.205%/+0.689%，2024分别+0.761%/+0.744%。应优先检查季节×时效×功率/爬坡的交叉分组，不能把全年2024模式直接解释为固定结构瓶颈。

还需对齐月份：2024剔除11月，而2023保留。仅按起报日期去掉2023年11月的敏感性分析后，W0全年RMSE优势由0.397%缩至0.124%，仍优于TF。这个分析未精确匹配2024边界剔除样本，不能代替严格样本匹配。说明年度比较部分受月份构成影响。

## 2. 固定3h切换可直接用现有统计计算

对每个场站和seed，按时效拼接MAE；RMSE先拼接各时效MSE再开平方，最后站内平均seed、站间等权平均。不需要逐样本预测。软加权平均两个模型则需要误差交叉项，不能由边际RMSE重建。

|固定前3h W0、后3h TF，相对TF|MAE变化|RMSE变化|MAE/RMSE胜场|
|---|---:|---:|---:|
|2023|-0.611%|-0.219%|54/40|
|2024|-0.447%|-0.040%|47/29|

2024组合RMSE只改善0.0399%，没到0.1%门槛；2023组合虽优于TF，却不如纯W0。它只能检验固定组合的互补性，不能证明单模型的α机制能复制或超越组合。3h分界来自已看过的2024，2024组合结果只能作事后分析。

## 3. 当前两个模型都使用固定锚点、零初始化

实现核查：physical_models.py 的W0为o+readout(decoder)，TF为o+head([decoder,o])；TF的最后线性层也显式零初始化。主要读出差别：

- W0：64→32→1，2,113个读出参数，o通过历史编码间接到达输出头。
- TF*：65→64→1，4,289个读出参数，输出头直接读取o。

因此TF并不是取消了固定锚点。W0的修正量没有幅度约束，理论上可学到任意目标−o；固定锚点更可能改变优化偏好、样本效率、有限容量下的信息通路，不能称为硬表达能力限制。旧协议DIRECT的微小改善是动机，不足以定位本业务设定的原因。

对ŷ=α(τ,s)o+c(τ)而言，如果c同时能读取历史状态，那么c与α可互相补偿：任意改成α′，取c′=c+(α−α′)o，输出不变。因此不能只凭学出的α随时效下降，就把它认定为物理惯性衰减。若要这种解释，需要更受约束的天气支路/混合结构及干预支持；否则称状态条件化预测权重更准确。

## 4. “和区域模块无关”不能成立

2024不加区域时，W0_SEL−TF_SEL的平均RMSE差为0.00009684；加入相同区域输入后差为0.00045047，差距扩大0.00035363。按这个差分，占最终差距约78.5%。这是效果差异的代数分解，不是区域模块造成错误的因果证明，但足以反驳“输入相同所以与区域模块无关”。TF从区域实况得到的RMSE增益大于W0。

2023也存在TF获得更大区域增益的现象，只是W0原有优势尚未被反转。因此应同时研究区域信息在两个骨干中的读出/融合效率，不能只研究天气主路径。

## 5. 预报年龄和钟点完全绑定

逐条检查2023和2024元信息，全部满足：

年龄[h] = 12 + ((北京时间小时 − 8) mod 12)。

年龄16–20h对应北京时间00:00–03:45与12:00–15:45。固定08/20发布、12h可用的协议下，同一当地时刻没有不同的最新预报年龄，所以这不是一般的可用回归控制消除的混杂。可分别比较两个半日窗口作为描述性线索；要识别年龄效应，需要同一功率起点使用不同但均已可用的发布周期等对照，不能用未来才可用的NWP。

## 6. 分组贡献需匹配主表统计口径

原表71%、33%、84%、69%等基本可复现，但它们对应合并SSE差额的贡献，不是主表“逐站逐seed RMSE取平均”差额的精确贡献。与主表完全一致的加法分解是：对每个场站seed，用组内ΔSSE除以N×(RMSE_W0+RMSE_TF)，再对场站seed平均。各组在同一分组轴内相加等于整体RMSE差。

|2024分组|组内宏平均RMSE变化|原合并SSE贡献|匹配主表的RMSE贡献|
|---|---:|---:|---:|
|当前功率0.1–0.3|0.755%|71.4%|58.8%|
|当前功率0.3–0.7|0.412%|33.2%|34.6%|
|当前功率≥0.7|0.138%|-2.6%|-1.2%|
|预报年龄16–20h|0.830%|83.9%|78.9%|
|冬季|0.761%|68.9%|58.3%|
|夏季|0.744%|45.2%|42.7%|

中等功率仍是主要来源；高功率不是总体差额的主要来源，但该组宏平均RMSE仍略差0.138%，不能说完全没有损失。不同分组轴（功率、季节、年龄）的贡献不能相加；同一分组轴内可有负贡献，因此正贡献合计可以超过100%。当前功率分组也不等同于观测到了未来的功率曲线斜率，限电/可用容量等会破坏一一对应。

## 7. 更合理的下一轮顺序

1. 已完成的零训练分析：逐时效/现有场景对比、固定3h组合、时间混杂、月份敏感性。真正需要2023推理重放的是联合分组、误差尾部、上/下坡偏差方向及原始预测层面的校准诊断。

2. 先做输出头2×2：是否直接输入o × 隐层32/64。四格含现有W0原型，只有三格需新增训练。统一零初始化、学习率、dropout、训练预算和选择规则；这样可把o的直接通路与参数容量分开。原A3一次同时改两件事，归因不够干净。

3. 只有2023的联合诊断/输出头实验支持“状态保持过强”时，再比较A1状态门控与A2仅时效门控。门控网络结构和维度相同，A2的状态槽用训练期固定统计量，另设训练时状态错配等对照；报告新增参数和推理代价。若只做αo+c，不将α视为可识别的物理时间常数。

4. 必须补入相对原W0_R3_RAW的增量标准。2023原W0已经双指标优于TF，A1仅超过TF和另外两个改动版，仍可能比原W0退步。两种子阶段只和基线相同两seed配对；候选再扩十seed核验，并检查短时效保留、高功率和冬夏场景。A4应与未改TF比较，A1也应与加同机制的A4公平比较。

5. 最终2×2中，所有由本站历史产生的门控状态特征必须随历史因子一起固定，天气派生特征随天气因子一起固定；当前功率锚点是否保留须预先定义，避免真实状态从新门控绕过消融。

## 8. 测试集独立性

本次新想法已经受到2024结果启发，再在2023复现可以减少盲目试错，却不能恢复2024作为独立确认集的地位。保留当前冻结主表；后续2024结果标为探索性复评。如要对新机制作独立确认，优先使用未参与设计的新时间段/新年份，并事先冻结。没有新测试数据时，不把反复查看2024后的改进称为完全独立验证。

本次结论：值得做诊断和低成本读出对照，不建议把状态依赖锚点衰减直接作为已经有证据支持的主机制，也不建议据此立即批量启动A1–A4。
