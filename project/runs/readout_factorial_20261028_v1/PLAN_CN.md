# 输出头2×2验证

本轮只回答：输出头直接读取当前功率、或增加隐层宽度，是否改善最终W0的MAE与RMSE。

五组为W0_H32、W0_H64、W0_O_H32、W0_O_H64及TF_R3_RAW。前四组构成“是否读当前功率×32/64宽度”的2×2；所有组输入均为SEL及R3_RAW。每组56站，种子42–51，共2800次独立训练。

2022训练不变。2023验证剔除11月，以及功率窗口、天气窗口或预报起报点触及11月的边界样本；32550个起报样本保留29695个。早停、checkpoint选择、模型比较均用同一掩码。原W0与TF也重训，避免旧参照通过完整2023选择checkpoint造成不公平。归一化仅来自2022。

保留现有持续法锚点与零初始化，不引入门控或衰减机制。W0各组共享部分的初始权重、输出头共有坐标的初始权重及训练随机数状态一致。MAE训练、80epochs上限、10epochs耐心、batch256、学习率0.0002及dropout均沿用原配置。

先在站内平均10种子，再对56站等权平均。新变体必须相对原W0及同输入TF同时达到MAE、RMSE改善至少0.1%，且每个指标至少29站改善；高功率组RMSE退化不得超过0.5%，相对原W0的0–1h MAE/RMSE退化不得超过0.1%。全部2800项完成后才选择；多个通过则按2023 MAE选择。完整报告2×2对照、交互、逐站/种子/时效/场景指标及配对风场bootstrap区间。后者只是描述性区间，不能消除空间依赖与跨年不确定性。

未通过不等于W0与TF等效，也不自动切换主模型。本轮不评估2024。完成后自动审计checkpoint与覆盖率，生成SELECTION_FREEZE.json；任何后续2024复评须基于冻结方案，并注明此前已查看2024，属于探索性复评。保留此前主表不变。

运行机器仅4090本机、v1006001及v1006002。每卡可多进程，依据显存、GPU计算负载、CPU/RAM及实测epoch吞吐逐步加并发。至少预留4GiB或20%显存；单任务因并发持续慢于参照1.5倍时收缩。4090检测到其他任务活跃会等待，必要时本轮任务保存状态退出、稍后续训。两台V100允许利用现有计算余量。

代码位于本目录；jobs、smoke_jobs、analysis链接到SSD3。逐站表位于analysis/stations/，总表为analysis/per_farm_seed_year.csv，结果与判定为analysis/FACTORIAL_RESULTS.json及analysis/REPORT_CN.md。STATUS.json和operations/REMOTE_STATUS.json记录进度。
