# 三机执行入口

launch_round.py 启动独立的本轮队列、中央回传与自动审计。bootstrap_limits.py 保留4090的空闲等待；两台V100也先核验兼容性。账号内存检查和进程启动预留作用于所有本项目任务，旧ARX会计入资源使用；不复制或终止其运行。

中央 worker.lock 和远端租约防重复执行。重放仅传输选定源权重与原指标/标准化，成功回传核验后删除本次临时远端源权重；训练最多保存两份选定权重。复用旧权重的MAE/RMSE一致性容差保持2e-6。逐任务 FAILURE.json 保留异常，两个失败触发该机熔断，防止无效批量训练。

STATUS.json 是当前成功/失败/运行计数，operations/REMOTE_STATUS.json 是远端连接和租约。旧轮的完成状态不能替代本轮状态。E 阶段不在此启动脚本中：先完成 D 判定与 E 冻结。
