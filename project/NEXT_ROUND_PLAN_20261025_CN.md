## 1. 筛选结论

### 1.1 输入增强（56 站，2 seeds）

| 输入 | W0：MAE / RMSE（MAE 改善站数） | TF：MAE / RMSE（MAE 改善站数） |
|---|---|---|
| **DENS**（密度、密度修正风速、风能代理 ρv³） | **−1.34%** [−1.56,−1.11] / −1.16%（54/56） | −0.15% / −0.29%（38/56） |
| **ALL**（全部组合） | **−1.89%** [−2.31,−1.49] / −1.73%（50/56） | **−1.16%** / −1.41%（47/56） |
| ALL 相对 DENS | −0.56% / −0.58%（34/56） | −1.02% / −1.12%（47/56） |
| DYN（地转风、温度平流、气压倾向等） | −0.32% / −0.51%（37/56） | −0.22% / −0.34%（36/56） |
| STAB（稳定度代理） | −0.33% / −0.32%（35/56） | −0.14% / −0.12%（34/56） |
| STATE（历史波动、趋势、平台） | −0.19% / −0.11%（37/56） | −0.45% / −0.35%（42/56） |
| CAL（当地时刻、年周期） | **+0.44%**（变差） | +0.11% |
| REF（起报天气代理） | **+0.55%**（变差） | −0.10% |
| DELTA（天气变化量） | +0.56%（相对 REF 无差别） | −0.18% |
| CYCLE（相邻发布周期差） | **+0.28%**（8/56） | +0.05% |

- **DENS 的分时效**（W0）：0–1 h 为 −0.05%（无效果），1–3 h 为 −1.25%，3–6 h 为 −1.59%。收益集中在天气主导的时段，与物理预期一致。
- **容量对照**（6 站）：W0 的 DENS 相对同维度容量对照为 −1.90%（12/12 对改善），不是额外参数带来的。
- **同输入骨干比较**（2023）：W0 相对 TF，BASE 时 MAE −2.49%（55/56）、RMSE −1.04%；DENS 时 −3.65%（56/56）、RMSE −1.90%（49/56）。但 2024 年 BASE 的 RMSE 曾反转，必须跨年复评。

**对 DENS 的解释（需验证）**：E2C 的 15 维柱坐标里只有风矢量分量，**没有风速模长**。DENS 首次显式给出风速，以及接近功率曲线的 v³ 变换。增益很可能主要来自“功率相关的风速非线性变换”，而不是空气密度本身：吉林年内密度变化约 ±10%，对功率的影响远小于风速三次方的作用。这与之前“历史×天气交互源于功率曲线非线性”的解释是一致的。

### 1.2 损失函数（56 站）

| | MAE | RMSE |
|---|---|---|
| W0，MSE 训练对 MAE 训练 | +3.43% | +0.04% |
| W0，MIX 训练对 MAE 训练 | +2.07% | −0.19% |
| TF，MSE 训练对 MAE 训练 | +4.07% | +0.51% |

换损失没有改善 RMSE，却明显损害 MAE。**RMSE 劣势不是 MAE 训练造成的**，这条线停止。

### 1.3 结构性机制（6 代表站，2 seeds，12 对）

| 机制 | W0 | TF | 判断 |
|---|---|---|---|
| HIST（加入起报前历史天气节点） | MAE +1.82%（1/12） | +0.06% | 无效，W0 上有害 |
| SHIFT_FIXED 对 SHIFT_ZERO（全站固定时间偏移） | +0.13% | −0.19% | 无稳定效果 |
| SHIFT_SAMPLE 对 SHIFT_FIXED（样本自适应时间偏移） | +0.07% | +0.16% | 无效 |
| PC_INPUT 对 BASE（REF + DENS 输入） | **−1.34%**（11/12） | −0.48% | 收益来自 DENS 输入 |
| CURVE_FREE / CURVE_BIAS 对 PC_INPUT（功率曲线结构） | −0.02% / −0.06% | +0.11% / +0.05% | 结构本身无增量 |
| NEIGH_GENERIC 对 CAL（邻站观测） | −0.37%（11/12） | −0.05% | 小幅、仅 W0 |
| NEIGH_ADVECT 对 NEIGH_GENERIC（平流先验） | +0.38% | −0.15% | 平流先验无效 |
| 邻站 0 分钟延迟对 15 分钟 | −0.31% | −0.04% | 很小 |
| 邻站 30 分钟延迟对 15 分钟 | +0.12% | +0.23% | 延迟越大越差，方向合理但很小 |

- 邻站干预：W0 的邻站输入置零后误差上升 5.6%，但邻站带来的净增益只有 0.37%。说明模型学会了依赖邻站输入，却没有因此显著变好；置零属于分布外干预，不能作为价值证据。

### 1.4 总判断

1. **成立的方向**：显式的、与功率相关的天气物理量，即 DENS，以及组合 ALL 中的 DYN、STAB、STATE。证据为 56 站一致、容量对照排除、收益集中在 1–6 h。
2. **停止的方向**：
   - 时间位移（固定或自适应）、历史天气节点、显式功率曲线结构；
   - 平流先验、相邻发布周期差；
   - 天气变化量参数化、日历特征；
   - 换损失。
3. **待定**：邻站观测只在 6 站上测过，增益小且只出现在 W0；它会改变“仅本站输入”的协议。放在 P2。
4. **新的论文主线候选**：在单站数据下，网络不能从风矢量分量中自行学到功率相关的非线性量（E2C 的 MLP 编码对 E0 无增益，可作佐证），显式物理变换才带来稳定增益；这些增益与历史状态条件化的作用位置相互印证。这一主线需要下一轮的分解实验来支撑。

## 2. 下一轮实验计划

**统一协议**
- 单站独立训练；FP32；2022 训练、2023 选择；MAE 训练、MAE 选权重（RMSE 选权重作为预先声明的次要结果）。
- A 阶段 56 站 × 2 seeds（42、43），**只用 2023**。
- A 阶段结束后，**冻结最终变体清单与比较清单，写入 FROZEN 文件，再进入 B 阶段开 2024**。
- W0 与 TF 两个骨干都做，保证同输入比较。

### A 阶段：归因与选型（只用 2023）

**A1. DENS 分解（核心，P0）**

| 变体 | 新增输入 | 回答的问题 |
|---|---|---|
| SPD | 10 m 风速模长 \|v10\| | 是否只是缺了风速模长 |
| SPD3 | \|v10\|³ / 1000 | 三次方非线性的作用 |
| SPD_LV | \|v10\|、\|v1000\|、\|v925\| | 多层风速模长 |
| SPD3_LV | 三层风速的三次方 | 多层的功率代理 |
| RHO | 仅 ρ / 1.225 | 密度单独的作用 |
| DENS_NORHO | 与 DENS 同形式，但 ρ 固定为 1.225 | 去掉密度后 DENS 是否保留增益 |
| DENS | 原 DENS（复用已有结果） | 参照 |

- 规模：6 个新变体 × 56 × 2 seeds × 2 骨干 = 1,344。
- 期望检验（预先写定）：若 SPD 或 SPD3 接近 DENS、RHO 接近 0，结论写为“风速模长和功率相关非线性”，而不是“密度修正”。

**A2. 组合精简（P0）**

| 变体 | 内容 | 理由 |
|---|---|---|
| SEL | DENS + DYN + STAB + STATE | 去掉单独有害的 CAL、REF、DELTA、CYCLE |
| SEL − DYN / − STAB / − STATE | 逐项去除 | 各组分在组合中的必要性 |
| SEL + REF + DELTA | 把起报参照加回 | ALL 中 REF/DELTA 是否有交互收益 |
| （若 A1 有更优的风速变体）SEL′ | 用 A1 最优变体替换 DENS | 用最简洁的物理量组合 |

- 规模：约 5 个变体 × 56 × 2 × 2 = 1,120。
- 冻结规则：在 2023 上，ALL、SEL 和各精简版中，MAE 最低者为主变体；若与次优者差距小于风场 bootstrap 区间，取输入更少的那个。

**A3. 骨干公平性（P0）**

现象：DENS 对 W0 的增益（−1.34%）远大于对 TF 的增益（−0.15%）。需要排除这是 TF 实现上的劣势。

| 变体 | 改动 |
|---|---|
| TF_ZI | TF 输出头零初始化（起点等于持续法），其余不变 |
| TF_ZI + DENS / TF_ZI + 主变体 | 同上，加物理输入 |
| TF_LR | TF 用 W0 的 lr 2e-4 与 dropout 0.05 |

- 规模：4 × 56 × 2 = 448。
- 目的：确认 W0 的骨干优势（2023 年 MAE −2.49%）与物理输入优势分别来自哪里。若 TF_ZI 追平 W0，论文中骨干只作为实现，贡献集中在物理输入与交互分析。

**A4. 收益的物理定位（零训练）**

用 A1/A2 的 2023 预测，按以下分组看 DENS 和主变体对 BASE 的误差差：
- NWP 风速区间：切入以下 / 曲线中段 / 接近额定 / 额定以上，阈值用 2022 分位；
- 当前功率区间、稳定度代理、季节；
- 过去 1 h 爬坡与按 NWP 预报风速变化定义的“预报爬坡”（不用未来真值）。

期望：收益集中在功率曲线斜率大的风速段（中段）以及预报有爬坡的样本。这是“功率曲线非线性”解释的直接证据。

### B 阶段：冻结后的跨年复评（开 2024）

**B1. 主表**（56 站 × 10 seeds，42–51，已有 seed 复用）
- W0 + BASE、W0 + 主变体、TF + BASE、TF + 主变体；若 A3 中 TF_ZI 更强，加入 TF_ZI 的两个版本；
- 规模：约 4–6 个模型 × 56 × 8 个新 seed ≈ 1,800–2,700。
- 报告：
  - 全时效、0–1 / 1–3 / 3–6 h 的 MAE 与 RMSE；
  - 场景（爬坡、高功率、季节）；
  - 逐风场胜率与失败风场；
  - 2023→2024 的方向一致性。

**B2. 交互在新输入下是否仍成立**（56 站 × 5 seeds）
- 以主变体为输入，重做 2×2：真实/固定历史 × 真实/训练均值天气；
- 规模：3 个新模型 × 280 = 840；
- 回答：物理输入增强后，历史×天气交互是否保持，以及物理量的增益是否也依赖历史状态。

### C 阶段：可选

- **C1. 邻站观测扩展到 56 站**（W0、0 分钟延迟、2 seeds、2023）：只有在论文接受“使用邻站观测输入”的协议时才做。只测 NEIGH_GENERIC，不再测平流先验。

## 3. 结果出来后的写作判断

| A1 结果 | 论文中的物理量表述 |
|---|---|
| SPD/SPD3 ≈ DENS，RHO ≈ 0 | 显式风速模长与功率非线性变换是关键，密度不是 |
| RHO 有独立增益，且冬季更明显 | 可写空气密度修正 |
| 仅 DENS 的组合形式有效 | 只能写“风能代理组合”，不拆分归因 |

| B1 结果 | 主张 |
|---|---|
| 2024 上 W0 + 主变体对 TF + 主变体，MAE 与 RMSE 都占优 | 可同时写方法优势与物理输入贡献 |
| 只有物理输入在两个骨干上都有效 | 贡献写为“与骨干无关的物理天气表示”，骨干只作实现 |
| 2024 增益明显缩小 | 如实报告跨年衰减，论文以分析为主 |
