# 邻站功率能否成为第二个贡献点：评估与实验计划

日期：2026-10-25。

**贡献结构（用户确定）**
- 贡献一、二为机制贡献；
- 贡献三为指标优势；
- 每项都必须在 MAE 与 RMSE 上同时成立（2024 跨年复评，均改善 ≥0.1%，且两个指标各自都有过半风场改善）。

## 0. 结论

**有潜力，但要换一种用法。**
- 邻站的价值不在其**功率本身**，而在其**刚刚实现的预报偏差**（实测 − 1 h 前对该时刻的预报）。
- 现有 NEIGH 模块输入的是邻站原始功率，因此增益很小、RMSE 不稳定。
- 零训练诊断显示，加入邻站的已实现偏差后，在目标风场自身偏差之外还能额外降低误差，两个指标都达到 0.1% 门槛，且主要集中在 0–3 h。
- 端到端模型尚未验证，需要按 §4 的计划完成。

## 1. 现有邻站实验为什么不够

| 实验 | 输入 | 结果 |
|---|---|---|
| IC 对 IL（独立训练，56 站） | 56 站加总的区域功率 | MAE +0.26%（变差） |
| NEIGH_GENERIC 对 CAL（W0，6 站 × 2 seeds） | 8 个最近邻的**原始功率**与变化量，注意力读取 | MAE −0.37%（11/12 对），RMSE −0.19%（**8/12**）；0–1 h 的 RMSE 只有 6/12 对改善 |
| NEIGH_ADVECT | 在上一行基础上加平流先验 | 无增益 |

实现上的局限（`physics_observation_single_farm_20261024_v1/code/physical_models.py: NeighborReadout`）：
- value 只有邻站功率与差分；
- 邻站的功率水平混杂了各自的装机、功率曲线和运行状态，无法直接告诉目标风场“这次天气预报偏强还是偏弱”。

## 2. 零训练诊断：邻站信息的潜力在哪里

脚本：`runs/neighbor_potential_diagnostic_20261025/neighbor_potential.py`；结果：同目录 `neighbor_potential_per_farm.csv`。

**方法**
- 预测：已有独立训练 E2C_CBH（seed 42）在 2023 年的预测。未读取 2024。
- 对每个目标风场、每个时效，用起报时可得的信息线性回归其预测残差：2023 上半年拟合，下半年评价。
- 用两种拟合方式：
  - L1 拟合（近似最小绝对偏差），对应 MAE；
  - L2 拟合，对应 RMSE。
- 信息组：
  - SELF：目标风场自身已实现的偏差，取起报时刻和 15 分钟前；
  - +RAW：邻站原始功率与 1 h 变化，即 NEIGH_GENERIC 用的信息；
  - +ERR：8 个最近邻（150 km 内）已实现的偏差，有 15 分钟数据延迟；
  - +BOTH：RAW 与 ERR 两者都加。
- 性质：这是线性事后修正，只估计信息量的下限，不等于端到端模型的效果。

**结果（L1 拟合；“对 SELF”= 在目标自身偏差之外的增量）**

| 信息 | 时效 | MAE 对 SELF | RMSE 对 SELF |
|---|---|---|---|
| +ERR（邻站已实现偏差） | 全时效 | **−0.15%（42/56）** | **−0.36%（52/56）** |
| | 0–1 h | **−0.52%（50/56）** | **−1.03%（54/56）** |
| | 1–3 h | −0.25%（42/56） | −0.56%（51/56） |
| | 3–6 h | −0.02%（29/56） | −0.18%（47/56） |
| +RAW（邻站原始功率） | 全时效 | **+0.40%（变差）** | +0.05% |
| | 0–1 h | −0.18% | −0.71% |
| +BOTH | 全时效 | +0.27%（变差） | −0.33% |

**要点**
1. **信息类型决定价值**：已实现偏差在两个指标上都有增量；原始功率在线性修正中让 MAE 变差，RMSE 也无增量。这正好解释了现有 NEIGH 增益小的原因。
2. **随时效衰减**：0–1 h 最大，3–6 h 接近 0。这与“预报误差在空间上相干、随时间持续但逐渐衰减”的物理图景一致。
3. **与距离的关系不是简单的“越近越好”**：最近邻站距离与 RMSE 增益的 Spearman 系数为 −0.31（p=0.02），也就是最近邻越远的风场增益越大（最近邻 >15 km：−0.45%；<5 km：−0.30%）。一种可能的解释是：非常近的邻站与本站天气几乎相同，其偏差和本站自身偏差高度冗余。这只是推测，论文不能写成距离衰减。
4. 目标自身已实现偏差（SELF）本身也有价值（RMSE −0.32%），所以贡献必须以 SELF 为对照，证明的是**邻站的增量**。

## 3. 作为第二个机制贡献的表述（待端到端验证）

> **贡献二：邻近风场已实现预报偏差的同化。** 邻近风场的价值不在其功率本身，而在其刚刚实现的预报偏差。这类偏差可视为区域天气预报误差的实时观测；目标风场据此修正以天气驱动的预测，主要改善 0–3 h，并同时降低 MAE 与 RMSE。

与贡献一的关系：贡献一说明天气的作用取决于本站当前状态；贡献二说明天气的可靠程度可以由邻站的实况在线修正。两者合起来回答：天气信息如何被本站与区域的实时观测共同校准。

与已有工作的区别（需在相关工作中说明）：
- 不同于把邻站功率当作时空输入（GNN 一类）；
- 不同于平流或上游传播（本项目已验证无效）；
- 与 NWP 偏差校正、MOS 的思想相近，但这里用的是**邻站实时实况**、在 6 h 内对单站进行学习式同化。

## 4. 下一轮实验（只用 2023，56 站 × 2 seeds）

### 4.1 偏差的定义（关键）
邻站已实现偏差 = 邻站实测 − 对该时刻的参考预报。参考预报有两种做法：

| 记号 | 参考预报 | 优点 | 风险 |
|---|---|---|---|
| ERR_NWP | 每站用 2022 数据拟合的简单“NWP 风速 → 功率”曲线（单变量单调曲线） | 不依赖预测模型；物理含义直接：就是 NWP 的误差；部署最简单 | 偏差中混有功率曲线拟合误差 |
| ERR_MODEL | 邻站自身预测模型 1 h 前的预报 | 与诊断一致，信息最强 | 训练集上的预测是样本内预测，偏差偏小。**必须用交叉拟合**：2022 按季节分 4 折，每折用其余 3 折训练，生成样本外预测 |

建议主变体用 ERR_NWP，ERR_MODEL 作为对照。

### 4.2 变体（骨干 W0 + SEL；邻站 8 个最近、150 km 内、15 分钟延迟）

| 编号 | 变体 | 作用 |
|---|---|---|
| N0 | SEL | 基准 |
| N1 | SEL + 本站已实现偏差 | 自身偏差对照（必要） |
| N2 | N1 + 邻站原始功率（现有 NEIGH 形式） | 信息类型对照 |
| **N3** | **N1 + 邻站 ERR_NWP** | 主变体 |
| N4 | N1 + 邻站 ERR_MODEL（交叉拟合） | 偏差定义对照 |
| N5 | N3，但训练时邻站偏差取同月不同日 | 排除“只是多了参数或正则化” |
| N6 | N1 + 邻站偏差的简单平均（无注意力） | 检验逐站选择是否必要 |
| N7 | TF* + SEL + 本站偏差，与 TF* + SEL + 本站偏差 + 邻站 ERR_NWP 对比 | 与骨干是否无关 |

- 规模：约 7 个变体 × 112 + TF* 两组 224 ≈ 1,000 次训练；加上 ERR_MODEL 交叉拟合 56 站 × 4 折 = 224 次。
- 评价时干预：打乱邻站偏差的时间与身份；把延迟改为 0 / 15 / 30 分钟。
- 机制分析：
  - 按时效衰减；
  - 按邻站偏差的一致程度（各邻站偏差同号或离散度小）分组，预期一致时增益更大；
  - 按天气类型或季节分组。

### 4.3 判定规则（事先写定）
- N3（或 N4）对 N1：全时效 MAE 与 RMSE 都改善 ≥0.1%，且两个指标各自都有过半风场改善；
- N3 必须优于 N5 和 N2；
- 满足才进入冻结与 2024 复评，否则贡献二不成立，如实报告。

### 4.4 部署前提（论文中写明）
- 需要邻站的实时功率；ERR_NWP 另外只需各站位置上的 NWP，而格点 NWP 本来就是全区域共享的。
- 适用于调度端可获取全省风场实时数据的场景。
- 模型参数仍按风场独立训练。

## 5. 贡献三（指标优势）的要求
- 56 站、10 seeds、冻结后 2024 跨年复评；
- 对比对象包括调好的 TF*（含 TF* + SEL，以及若 N7 成立时的 TF* + 邻站）；
- 全时效与三个时效段的 MAE 和 RMSE 同时报告，并给出风场胜率与区间；
- 失败风场单列。

## 6. 风险
- 诊断增量偏小：全时效 MAE −0.15%、RMSE −0.36%，3–6 h 基本无增量。端到端效果可能更大，也可能更小。
- MAE 只有 42/56 站改善，刚过半数，是最可能不达标的一项。
- 若 ERR_NWP 无效、只有 ERR_MODEL 有效，部署需要所有邻站模型实时运行，贡献表述要相应调整。
