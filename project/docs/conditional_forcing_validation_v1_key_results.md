# 状态条件化未来强迫修正：关键验证结论

日期：2026-08-26

## 结论

附件的核心判断基本正确：决定性问题确实不是 DCT 频带，而是识别 correction 的收益来自未来天气、额外历史路径，还是二者的预测交互。补齐严格四格、受控天气置乱、弱锚定、horizon、seed diversity 和随机初始化控制后，当前最稳妥的机制表述是：

> **State-Dependent Future Forcing Correction**：未来天气本身提供很大的预测增量；额外历史路径在没有天气时几乎无效，但在天气存在时稳定提高天气到功率的映射能力，而且这一互补收益随预测时效增加。

这个方向值得继续。当前数据集内部的机制证据较强，架构创新性中等：显式基线加条件修正并非全新的算子，但“严格识别状态 × 未来强迫的预测互补性，并用锚定解决分解不可辨识性”可以形成清楚的论文主线。它仍需冻结方案后的 test 和跨数据集验证。

## 原说法中正确与需要修正的部分

正确：

- `C(H)` 是识别天气价值的必要对照，优先级高于 shuffle。
- shuffle 只能作为方向性证据，不能直接当作天气的因果贡献量。
- 无约束的 `B+C` 分解不可辨识，锚定预训练 `B0(H)` 比继续监督 `B≈Y` 更符合科学定义。
- horizon 和 seed error correlation 是重要的机制诊断。

需要修正：

- 原四格不严格：旧 `C(W)` 参数更少，`B(H)` 也不能代替 `C(∅)`。本实验改成相同的 1,287,343 参数 correction backbone、相同四槽输入，只对 correction 的 H/W 槽置零。
- `C(H,W)` 同时优于 `C(H)` 和 `C(W)`不自动等于“交互”。本实验正式计算差中之差。
- `B+C > Direct` 原先混入了 `B0` 预训练初始化收益。本实验增加完全同架构、但历史基线随机初始化的 10-seed 控制。
- 这里识别的是预测误差上的非加性互补，不是物理因果交互；四格中共同的 `B(H)` 始终看历史。
- 45 个 seed pair 不是 45 个独立样本。相关性差异按 UTC 日整体 bootstrap，而不是对 pair 做普通显著性检验。

## 实验口径

- 模型随机种子：42–51，共 10 个；所有正式模型组均为完整 10-seed 结果。
- 数据：仅使用 2023 validation；32,550 个完全对齐且唯一的 forecast origins，覆盖 359 个 UTC 日。test 未使用。
- 单模型：报告 10-seed 均值 ± 样本标准差；同 seed 配对 t 区间。
- ensemble、horizon、shuffle 和 diversity：10,000 次 sample-weighted paired UTC-day block bootstrap。
- 天气置乱：5 套置乱，在 480 个“UTC 月 × 起报相位 × NWP age × 当前功率十分位”层内进行；最小层大小 6，无固定样本，无保留原天气 cycle。

## 严格四格：天气是主增量，历史负责条件化天气

所有四格都包含共同历史基线 `B(H)`；表中的 H 只表示 correction 是否得到额外历史状态槽，`context` 表示 correction 只保留站点/目标时刻等共同上下文。

| correction 输入 | 单模型 MAE（MW） | 10-model ensemble MAE（MW） |
|---|---:|---:|
| `C(context)` | 411.962 ± 0.722 | 408.055 |
| `C(H)` | 411.609 ± 0.799 | 408.304 |
| `C(W)` | 274.231 ± 1.595 | 260.461 |
| `C(H,W)` | **259.946 ± 1.916** | **244.229** |

关键的 10-seed 配对结果：

- 天气在有 correction-history 时的收益：151.663 MW，95% CI `[150.214, 153.112]`，10/10 为正。
- 天气在无 correction-history 时的收益：137.731 MW，95% CI `[136.423, 139.039]`，10/10 为正。
- correction-history 在有天气时的收益：14.285 MW，95% CI `[12.993, 15.576]`，10/10 为正。
- correction-history 在无天气时的收益：0.353 MW，95% CI `[-0.188, 0.894]`，无可靠收益。
- 差中之差：`[天气有 H 时的收益] - [天气无 H 时的收益] = +13.932 MW`，95% CI `[12.599, 15.264]`，10/10 为正。

因此不能说“历史不重要”。正确解释是：`B(H)` 已吸收主要历史信息；在此基础上，再加一条历史 correction 路径本身几乎无用，但它能稳定改善未来天气到功率的条件映射。这排除了“收益主要是第二个 history residual learner”的解释。

## 时效规律

`C(H,W)` 相对 `C(W)` 的历史条件化收益在极短时效略有害，从 0.75 h 开始可靠为正，随后持续增强：

| 时效 | 历史条件化收益（MW） |
|---:|---:|
| 0.25 h | -2.587 |
| 0.50 h | -0.616 |
| 0.75 h | +1.146，95% CI `[0.060, 2.158]` |
| 1.00 h | +3.413 |
| 2.00 h | +10.594 |
| 3.00 h | +17.361 |
| 6.00 h | +29.195 |

差中之差与时效的相关系数为 0.983，24 步中 21/23 个相邻交互增量为正。结果支持：短时主要受当前状态连续性约束；时效拉长后，未来天气成为主要驱动，同时天气响应仍取决于起始发电状态。

## 受控天气置乱

- 原始 full ensemble MAE：244.229 MW。
- 置乱后 ensemble MAE：554.176 ± 2.056 MW。
- 惩罚：+309.947 MW，按 UTC 日 bootstrap 95% CI `[296.476, 323.394]`。
- 10/10 模型种子均恶化。

这说明模型强烈使用了真实的样本级未来天气对应关系。309.947 MW 不能解释为天气的因果贡献量，因为即使分层匹配，置乱仍可能制造分布外的 H–W 配对；天气的更干净增量证据来自严格四格。

## 随机初始化控制：结构收益不依赖 `B0` 预训练

随机初始化组与 full 使用完全相同的输入、损失、1,287,343 参数和 state 结构，只不加载历史 checkpoint。

| 模型 | 单模型 MAE（MW） | ensemble MAE（MW） |
|---|---:|---:|
| Direct d64 | 262.089 ± 1.787 | 250.203 |
| 预训练初始化 `B+C(H,W)` | 259.946 ± 1.916 | 244.229 |
| 随机初始化 `B+C(H,W)` | **258.015 ± 2.286** | **242.138** |

- 随机初始化 vs Direct：单模型改善 4.073 MW，95% CI `[2.517, 5.630]`，10/10 胜；ensemble 改善 8.065 MW，按日 CI `[4.897, 11.224]`。
- 随机初始化 vs 预训练 full：单模型改善 1.931 MW，但 95% CI `[-0.244, 4.106]` 跨 0；ensemble 改善 2.091 MW，按日 CI `[0.137, 4.005]`。

所以 `B0` 预训练不是显式 correction 优势的必要条件，validation 上也没有证据表明它提高最终精度。结合既有近容量 Direct 对照，收益不能简单归因于参数量。不过这仍是架构级预测证据，不是“加法分解”本身的因果证明；Direct 与 correction 的优化拓扑并不完全相同。

## 分解不可辨识性与弱锚定

无约束时，任意只依赖 H 的 `δ(H)` 都可在 `B` 与 `C` 间转移而保持 `B+C` 不变，因此分量不能直接解释。实验改用对冻结预训练 `B0(H)` 输出的弱 Huber anchor，而不是继续约束 `B` 对真实标签负责。

| 约束 | 单模型 MAE（MW） | ensemble MAE（MW） | `B` 相对 `B0` 漂移（MW） |
|---|---:|---:|---:|
| 无约束 | 257.532 ± 2.633 | 244.797 | 608.449 |
| anchor 0.05 | 257.317 ± 3.360 | 242.584 | 152.082 |
| anchor 0.10 | 257.172 ± 1.676 | 243.182 | 106.828 |
| anchor 0.20 | 258.311 ± 1.583 | 242.915 | **77.289** |
| 原 target auxiliary 0.5 | 259.946 ± 1.916 | 244.229 | 103.334 |

无约束时 correction 绝对幅度为 666.615 MW，说明 `B/C` 确实在大幅互相抵消。anchor 0.20 相对无约束的漂移差为 -531.160 MW，95% CI `[-558.936, -503.384]`，10/10 均降低；单模型 MAE 差异的 CI 跨 0，ensemble 反而改善 1.881 MW，按日 CI `[0.319, 3.467]`。它相对原 target auxiliary 还进一步降低漂移 26.045 MW，并改善单模型 1.635 MW、ensemble 1.314 MW。

因此 anchor 0.20 是当前最保守的**可解释性候选**，不是根据最低 validation MAE 选出的预测最优点。三档权重均已查看 validation；若采用它，应现在冻结并只在未触碰 test 上确认。所有 anchor checkpoint 内的 `B0` state 与原 checkpoint 逐张量完全一致，预测重放平均数值差约 0.011 MW。

## Ensemble diversity

| 模型 | 平均 seed-pair 误差相关 | seed 间预测分歧（MW） |
|---|---:|---:|
| Direct d64 | 0.908 | 111.965 |
| 预训练 full | 0.883 | 127.497 |
| 随机初始化 full | 0.887 | 126.893 |
| 无约束 | 0.908 | 114.937 |
| anchor 0.20 | 0.888 | 126.148 |

按 UTC 日 bootstrap，预训练 full 相对 Direct 的相关性降低 0.0254，95% CI `[-0.0305, -0.0203]`；随机初始化 full 相对 Direct 降低 0.0219，CI `[-0.0278, -0.0164]`；anchor 0.20 相对无约束降低 0.0204，CI `[-0.0235, -0.0172]`。这支持“职责约束伴随更互补的 seed 解”这一解释，但相关性是结果诊断，不能单独证明约束造成了 diversity。

## 最终故事线与边界

第一性原理上，未来功率由当前潜在发电状态和未来外部强迫共同决定：历史功率 H 是当前状态的观测代理，未来天气 W 描述状态之后的外部驱动。因此合理的最小模型不是“历史负责高频、天气负责低频”，而是：

`Y_hat = B0(H) + C(H,W)`，并用弱 anchor 保持 `B≈B0`。

当前结果支持：

1. W 在已有历史基线和额外历史 correction 能力后仍有巨大增量；
2. H 对 correction 的主要作用是条件化 W，而不是再做一次独立历史残差拟合；
3. 这种预测互补随时效增强；
4. 显式 correction 的优势不依赖历史 checkpoint 初始化；
5. 弱锚定能以很小的精度代价大幅提高分解可解释性。

当前结果不支持：

- “天气只负责低频、历史只负责高频”或“天气提供高频信息”；
- 把 shuffle 惩罚解释成因果贡献量；
- 把 MAE 差中之差解释成物理因果交互；
- 声称该机制已跨站点、跨年份或跨 NWP 系统普遍成立。

下一步应冻结全频结构和 anchor 0.20 作为可解释主模型，用 untouched test 做一次确认；随机初始化 full 保留为结构控制。若 test 复现，再做跨区域/跨年份外部验证，而不是继续扩展 DCT、频谱 gating 或更复杂 fusion。
