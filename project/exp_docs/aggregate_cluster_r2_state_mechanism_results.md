# Aggregate R2 历史状态机制补充实验结果

## 最终结论

- 所有结果均为 seeds 42–51 的10个独立checkpoint `mean ± SD`，没有ensemble或挑选最好seed。
- 最终按2023 validation平均MAE选择 **R2-W**：删除修正分支的重复状态输入，采用更简洁的 B(H)+C(W) 结构。
- 历史基线继续使用过去3 h TCN。既有历史范围与状态范围搜索已经充分，本轮没有继续增加历史复杂度。
- 最终模型相对validation冻结的最强fusion baseline PredictionBlend：validation `-17.853 MW`，2024 `-16.627 MW`。
- R2-Full − R2-W：validation `+0.751 MW`，2024内部时间留出 `-2.387 MW`；负值代表Full更好。
- R2-Full − R2-Add：validation `-4.536 MW`。在保留状态输入的两种结构中，black-box联合条件化优于可加分解；但由于Full没有在validation上优于完全移除correction状态的R2-W，这不能单独证明状态—天气交互带来净增益。
- StateShift相对R2-Full：validation `+2.611 MW`，2024 `+2.614 MW`。该干预只诊断模型是否使用状态，是否有效以Full与重新训练R2-W的比较为准。
- Full/W在validation与2024发生方向反转，说明correction状态的增量不稳定。按预注册口径仍选择R2-W，不能利用2024反向改选Full。

## 解释边界

- 历史基线 `B(H_3h)` 已经吸收历史水平和演化信息，correction再次读取当前功率是否有增量由本轮直接回答。
- R2-W仍保留未激活的state encoder用于参数匹配，因此差异不是参数量变化造成的。
- 最终实现保留这些checkpoint参数键，但在weather-only correction下跳过未激活state encoder的前向计算；零状态参考测试确认预测公式不变，无需重训。
- StateShift保持baseline历史不变，只移动correction状态；它不能代替重新训练的无状态控制。
- 2024不参与结构选择，仅用于检查冻结结论的时间外一致性。
