# 跨分辨率实验关键结果

日期：2026-09-02  
状态：全部实验与冻结后的2024 internal test已完成

## 1. 时间侧正式结果（2023 validation，10 个独立 checkpoint）

| 方法 | 单模型 MAE（mean ± SD, MW） | 解释 |
|---|---:|---|
| T0 raw-linear | 261.616 ± 2.699 | 原始气象量先线性插值再编码 |
| T1 latent-linear | 258.274 ± 1.742 | 小时节点先编码，再在线性表示空间插值 |
| T2 nonlinear bracket | 258.813 ± 3.248 | 相邻小时节点的局部非线性映射 |
| T4 full-path attention | **257.692 ± 2.181** | 使用完整小时天气路径 |

所有数值都先对每个 checkpoint 单独计算，再跨 seed 汇总；没有把十个模型的预测平均成一个结果。

预注册主比较：

- T2−T0 = **−2.802 MW**，9/10 seed 获胜，95% CI `[−4.789, −0.816]`，Holm 校正后 `p=0.022`。差异显著，但未达到预注册的至少 3 MW 效应门槛。
- T2−T1 = **+0.539 MW**，仅4/10 seed 获胜，95% CI `[−1.196, 2.274]`。T2 没有优于 T1。
- T2−T4 = **+1.122 MW**，1 MW 非劣检验的单侧95%上界为 `2.548 MW`。T2 未通过对 T4 的非劣检验。

用于选择失败后的实用回退结构的描述性比较：

- T1−T0 = **−3.341 MW**，9/10 seed 获胜，95% CI `[−4.938, −1.745]`。
- T1−T4 = `+0.582 MW`，5/10 seed 获胜，95% CI `[−0.807, 1.972]`，没有证据支持把更复杂的 full-path attention 写成核心方法。

## 2. 机制判断

T1 相对 T0 的收益主要来自中长时段：短、中、长三个时段的差值分别为 `+0.012`、`−2.248`、`−5.188 MW`。这支持“先把小时天气编码成任务相关表示，再插值”优于直接在原始气象变量上插值，但它不是短时收益。

T2 相对 T1 在短、中、长时段分别为 `+0.897`、`+1.113`、`+0.037 MW`；按小时内位置分组，整点、+15、+30、+45分钟分别为 `−0.262`、`+0.541`、`+1.161`、`+0.716 MW`。局部非线性 bracket 并没有在非整点位置形成优势，+30分钟反而最差。因此三 seed 的正结果不能升级成“非整点响应映射”贡献。

## 3. 冻结决策

- 时间结构选择 **T1 latent-linear**。
- 时间跨分辨率降级为任务背景，不作为已证实的方法贡献。
- 按预注册 gate 停止 T2-PhaseOff、T2-Linear、T2-NoDiff 的扩展；这些实验不能在 T2 本身未成立后用于事后挽救主张。
- T2 分辨率鲁棒性实验同样停止，因为已不存在一个确认胜出的“最终 T2”。
- 下一步只完成仍独立成立的空间 same-support 最小矩阵，再训练冻结结构的 Normal/KD 单模型。

## 4. 空间 same-support 最小矩阵（2023 validation，3 seeds）

| 空间映射 | 单模型 MAE（mean ± SD, MW） |
|---|---:|
| S0 raw 2×2 bilinear | 257.826 ± 1.034 |
| S1 latent 2×2 bilinear | 257.716 ± 0.606 |
| S2 learned 2×2，无 wind geometry | 257.922 ± 1.663 |
| S3 fixed 4×4 Gaussian | 257.763 ± 0.660 |
| S4 learned 4×4，无 wind geometry | 258.728 ± 1.550 |
| S5 learned 4×4 + wind geometry | **256.589 ± 1.967** |

核心结论：

- S0−S1 = `+0.110 MW`，原始量先插值和 latent 先编码再插值在空间侧基本相同。
- S2−S1 = `+0.206 MW`，learned 2×2 未优于同支持的 fixed bilinear，且只有1/3 seed获胜。
- S4−S3 = `+0.965 MW`，learned 4×4 未优于同支持的 fixed Gaussian，且只有1/3 seed获胜。
- S3−S1 = `+0.047 MW`，扩大固定支持范围没有稳定收益。
- S4−S5 = `+2.139 MW`，S5 在3/3 seed上更好；这是 wind geometry 的小样本正迹象，但没有预注册的10-seed扩展依据，只能作为解释性观察。

S2、S4 均未通过扩展门槛，不补齐10 seeds。最简单的 fixed 方案相对 S5 的差值为：S1 `+1.127 MW`、S3 `+1.174 MW`、S0 `+1.237 MW`，都略超出预注册的1 MW简化范围。因此最终工程模型保留 S5，但 **不能声称 learned 4×4 attention 相对 same-support fixed 投影成立**；空间侧论文定位仍是 grid-to-station cross-support adaptation，不是空间超分辨率。

机器可读结果：`artifacts/cross_resolution_temporal_v2/spatial/analysis_screening/` 与 `spatial/analysis_formal/`。

## 5. 最终单模型（2023 validation）

时间 T1 + 空间 S5 的十个最终 Normal 与 Stage A 已审计 checkpoint 完全同配置，因此直接登记复用，没有制造重复确定性训练。十个 Normal 的训练集预测均值只作为 KD teacher；以下成绩全部来自独立 checkpoint，没有报告预测平均后的 ensemble 成绩。

| 模型 | cluster MAE（mean ± SD, MW） | RMSE（MW） | R² | station MAE（MW） |
|---|---:|---:|---:|---:|
| 最终 Normal（T1+S5） | 258.274 ± 1.742 | 373.743 | 0.9115 | 10.766 |

- 最终 KD−当前 KD = `+0.467 MW`，4/10 seeds 获胜，95% CI `[−0.666, 1.601]`；2 MW 非劣检验的单侧95%上界为 `1.386 MW`，validation 上通过非劣标准，但没有优越性。

|---|---:|---:|---:|---:|
| 最终 Normal（T1+S5） | 257.696 ± 2.691 | 378.740 ± 6.527 | 0.9010 ± 0.0034 | 10.497 ± 0.048 |
| 最终 KD（T1+S5） | **251.053 ± 1.725** | **371.241 ± 2.940** | **0.9049 ± 0.0015** | **10.369 ± 0.062** |

- 最终 KD−当前 KD = **+2.040 MW**，仅3/10 seeds获胜，95% CI `[0.235, 3.845]`。2 MW非劣检验的单侧95%上界为 `3.503 MW`，因此 **没有通过预注册的测试集非劣标准**。

最终 KD 相对 Normal 的收益随时距增大，但相对当前 full-path KD 的缺口也主要来自长时段。这与“full-path attention 在 Normal 的 validation 均值上没有明确优势”并不矛盾：它说明结构差异在蒸馏后及跨年份测试上可能放大，但该结果是在冻结测试后观察到的，不能据此返回2023重新选择结构。

冻结的代表 seed 46 在2024上的 cluster MAE 为：最终 Normal `253.999 MW`、最终 KD `252.868 MW`、当前 KD `247.233 MW`。代表 KD 只比自己的 Normal 好1.131 MW，且比当前 KD 差5.636 MW；不能改选另一个测试表现更好的 seed。

## 7. 统一结论与论文出口

1. **非线性跨分辨率机制未成立。** T2没有优于T1，也未通过对T4的非劣检验，因此不再声称非整点响应、连续时间或任意分辨率泛化。跨分辨率应降级为任务背景。
2. **时间侧最可靠的结构证据是“先编码、后对齐”。** T1稳定优于raw-linear T0，但该比较属于主假设失败后的描述性回退分析；同时T1与full-path T4没有可确认的差异。因此它更适合作为设计依据，而不是夸大成连续时间方法贡献。
3. **空间 learned-attention 贡献未成立。** learned 2×2和learned 4×4均未击败same-support fixed控制。S5仅因其三seed工程均值最好而保留，wind geometry的迹象只能作为后续假设，不能写成正式机制结论。
4. **ensemble的角色被严格限制为 teacher。** 共识蒸馏稳定改善了T1+S5的每一个学生，但最终评价仍是十个独立单模型；没有用十模型平均值作为最终性能。
5. **最终部署不替换当前 KD。** 新T1+S5 KD在validation上达到2 MW非劣，但在冻结2024上未通过，且代表seed明显较差。因此当前 `kd_l1_anchor_taper` 的full-path单模型仍是更稳妥的部署选择；新路线的价值是排除了过强的跨分辨率主张并明确了蒸馏与结构收益的边界。

建议论文表述为：

> 小时级规则网格NWP与15分钟场站功率之间存在时间和空间支持错配。实验支持先在任务相关表示空间处理小时天气，再将其用于状态条件化功率修正；但没有证据支持非线性bracket、任意分辨率泛化或learned空间投影优于same-support固定投影。full-path天气读取可作为最终工程模型的一部分，但不应包装成已验证的continuous-time机制。
