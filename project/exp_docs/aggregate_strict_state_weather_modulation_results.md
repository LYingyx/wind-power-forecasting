# Aggregate 严格状态—天气调制实验结果

## 结论

- 最终模型完全按2023 validation的10个独立checkpoint平均MAE冻结为 **A0-FT（R2-W低学习率继续训练）**；不使用ensemble，也不挑最好seed。
- 最佳严格候选是 **E1**。相对旧R2-W，validation MAE差值为 `-0.730 MW`，2024内部时间留出差值为 `-0.252 MW`；但相对预注册的A0-FT控制反而分别差 `+1.439 MW` 和 `+2.140 MW`。因此E1不能作为最终方法，也不能把它相对旧checkpoint的收益归因于状态调制。
- 最优可部署单模型是 **A0-FT**：它保持 `B(H_3h)+C(W)` 架构，只对完整R2-W天气解码器做低学习率继续训练；相对旧R2-W，validation改善 `2.169 MW`，2024改善 `2.392 MW`。
- E1相对旧R2-W的Ramp MAE差值分别为 validation `-0.546 MW`、2024 `-0.477 MW`；E1仍不如A0-FT，因此该动态指标改善只作为机制观察。
- 全局置乱状态使E1的MAE变化 validation `+9.005 MW`、2024 `+10.468 MW`；固定成训练参考状态的变化分别为 `+2.234 MW`、`+1.422 MW`。这证明E1确实使用状态，但“使用了”不等于“比无状态控制更有效”。
- 10个checkpoint的零天气latent状态不变性最大误差为 `0.000e+00`，因此代码中不存在状态直接产生correction的捷径。
- `Candidate-Const` 与A0-FT几乎完全一致，并且二者均优于E1，说明E1相对旧R2-W的表面增益主要来自嵌套继续训练，而不是状态路由本身。
- E1的三个专家平均占用率为 `[0.362, 0.309, 0.329]`，平均路由熵为 `0.931`（最大值 `ln(3)=1.099`）。路由没有塌缩，但非塌缩本身没有转化为超过无状态控制的净收益。
- 所有2024结果均在结构、候选和比较规则冻结后生成，不用于反向改模型。

## 机制诊断口径

- 状态只允许调制 `E_W(z,τ)=D_W(z,τ)-D_W(0,τ)` 或对天气latent做零保持变换。
- 状态表示只比较当前功率与3 h baseline latent，不重新搜索1 h/3 h/6 h历史窗口。
- `analysis/regime_matrix_val.csv` 和 `analysis/regime_matrix_test.csv` 给出当前功率五分位×未来10 m风速下降/稳定/上升×三个预测时段的45格结果；每格少于100个样本时仅记录、不解释。
- E1相对旧R2-W的主要改善集中在1–3 h；但其总体MAE仍差于A0-FT，Ramp改善也不能补偿这个差距。
- 45个状态—天气—时距单元中有33个在validation和2024上保持同号，说明调制效果具有明显的regime依赖，而不是全局一致收益。最强的跨split改善出现在“最低当前功率档、未来风速上升、1–3 h”，E1相对旧R2-W分别改善 `9.775 MW` 和 `13.285 MW`；但在“第二功率档、天气稳定、3–6 h”又分别恶化 `3.314 MW` 和 `9.203 MW`。这解释了为何模型会强烈使用状态，却不能降低总体平均误差。
- 正确的论文结论是：严格拓扑排除了旧black-box的state-only捷径；在这一公平设定下，状态路由虽形成非塌缩专家分工并对置乱敏感，却没有超过同训练预算的无状态天气响应映射。
