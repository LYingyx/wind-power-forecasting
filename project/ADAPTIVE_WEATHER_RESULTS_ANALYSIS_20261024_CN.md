# 自适应天气提取实验结果分析与论文路线判断

日期：2026-10-24。数据：`runs/adaptive_weather_single_farm_20261022_v1/analysis/`（8,016 次训练、7,840 次评价，全部完成；2023 选择已冻结，ST 组选定 k=5、前端 lr=2e-4）。

**统计口径**
- 原报告不跨 seed/风场平均。为判断效应量，本文另算均值：先站内平均 seed，再 56 站等权。
- Δ% = (候选 − 参考) / 参考，负值表示候选更好。
- 区间为风场 bootstrap 95% CI；“风场”列为候选更好的风场数。
- 默认 seeds 42–46；ST00/ST11 对 W0 用 42–51。2024 只能称跨年复评。

## 0. 结论

1. **路线一（跨时空自适应提取格点气象）不成立。** 这是一组设计完整、预先冻结的负结果：
   - 扩大空间邻域、跨小时节点读取、样本自适应权重，都没有带来有意义的提升；
   - 自适应版本**稳定地比静态版本差**；
   - 打乱自适应权重几乎不影响误差；门控很小；注意力没有上风向结构；
   - 接到 Transformer/TiDE 上也没有收益。
2. **路线二（历史状态如何决定天气的作用）获得强证据，但形式与原设想不同。**
   - 真实历史下，天气带来的增益是固定历史下的 2 倍（54/56 站），主要集中在 3–6 h；
   - 历史的作用位置在**天气→功率的响应**，而不在“提取哪些天气”：在提取权重里加入历史没有增量；
   - 冻结 B0 轨迹作为条件（H1）依然无用。
3. **当前预设路线不能直接写**，但可以改写为一个有证据的版本（见 §4），并补少量实验（见 §5）。

### 1.3 干预与诊断（2024）

| 诊断 | 结果 | 含义 |
|---|---|---|
| 天气错排（同月、同 phase，不同日） | 所有前端 MAE 上升 82–87%，每次都变差 | 模型确实在用本样本的天气，天气信息本身非常关键 |
| 自适应权重错排 | MAE 只上升 0.05–0.27%（静态权重为 0） | 样本自适应权重几乎没被利用 |
| 门控 tanh(gate) | 均值 −0.004 至 −0.16，最大约 0.5 | 最终输入接近点插值，且平均方向与候选分支相反 |
| 空间重心与上风向 | 上风向余弦 ≈ 0（S4 为 0.086），上风比例约 50% | 没有上风向偏好；重心约 47–56 km，接近 5×5 邻域的均匀分布 |
| 时间读取 | 0–1 h 期望节点偏后约 2.8 h，3–6 h 偏前约 1.2 h | 趋向读取窗口中部的整体上下文，没有可解释的滞后结构 |

### 1.4 判断

- 在 Pangu 0.25°、1 h 分辨率和单站一年训练数据下，**固定双线性取点 + 线性时间插值已接近该信息源的上限**。
- 静态注意力最多带来 0.1–0.2% 的改善；邻域展平反而变差。
- 样本自适应在空间、时间、时空、两种骨干上都是**一致的小幅退化**，区间不含零。
- 不能主张“自适应提取有效信息”，也不宜主张“跨时空邻域提取”。

可能原因（可写进讨论，但都还没验证）：
1. Pangu 场本身平滑，0.25° 格点在风场附近高度相关，邻域没有新增信息；
2. 单站一年数据不足以学会样本条件的提取函数；
3. 天气预报本身的误差掩盖了提取方式的差异。

## 2. 路线二：历史状态与天气的作用方式

### 2.1 历史 × 天气 2×2（2024 MAE，seeds 42–46）

| | 真实天气 | 训练期均值天气 | 天气增益 |
|---|---:|---:|---:|
| 真实历史 | W0 0.086925 | CLIM_LAST 0.107563 | **0.020638** |
| 固定历史（训练期均值） | H2 0.102486 | H2_CLIM 0.112764 | **0.010278** |

- 历史的价值：W0 vs H2 为 −15.2%，55/56 站。
- 天气的价值：W0 vs CLIM_LAST 为 −19.2%，55/56 站。
- **交互**：真实历史下天气增益比固定历史下多 0.01036（2023 年为 0.01243），54/56 站同向。
- 交互集中在远时效：

  | 天气增益 | 0–1 h | 1–3 h | 3–6 h |
  |---|---:|---:|---:|
  | 真实历史 | 0.0007 | 0.0113 | 0.0335 |
  | 固定历史 | 0.0003 | 0.0049 | 0.0172 |

- **反直觉之处正是证据力度所在**：固定历史时误差更大、改进空间更大，天气增益却反而只有一半。说明天气的作用强烈依赖当前运行状态，而不是简单相加。
- H2_CLIM（0.112764）与 Persistence 完全一致，说明对照构造干净。

### 2.2 历史的作用位置

| 对照 | 2024 | 含义 |
|---|---|---|
| ST11 vs ST_NO_H（提取权重里有/无真实历史） | +0.00%，32/56 | 历史不帮助“选哪些天气” |
| W0 vs H2（decoder 读真实/固定历史） | −15.2% | 历史决定“天气如何作用于功率” |
| H1 vs W0（加 b、Δb 条件） | +0.16%（区间跨零），30/56 | 冻结 B0 轨迹不需要 |

结论：历史功率的价值在于为天气→功率的响应提供当前状态，而不在于引导天气提取。

## 4. 论文路线判断与建议

**原路线（路线一为核心）：不能写。** 结果已经比较充分地否定了“自适应跨时空提取”在当前数据下有效。

**可写的路线**：以“天气信息的作用依赖当前运行状态”为核心，把路线一的负结果作为系统分析。

> 科学问题：小时级格点气象预报驱动 15 分钟单风场功率预测时，天气信息的价值来自哪里、如何作用于风场当前状态？

| 贡献 | 内容 | 证据 |
|---|---|---|
| 一（方法） | 状态条件化的天气修正：以最后观测为锚点，历史记忆作为 decoder 的状态，天气作为驱动 | 2×2 交互（54/56）；对强基线 MAE −1.2% 至 −1.4%；需补 §5 的 A1 |
| 二（分析） | 天气提取的受控分解：空间 / 时间 / 静态 / 自适应，容量匹配，加干预与跨骨干。结论：点插值已接近上限，自适应提取无收益；历史的作用在响应而非提取 | §1、§2.2，已完成 |
| 三（评估） | 分时效、逐风场、跨年评估：天气价值与历史×天气交互集中在 3–6 h；0–1 h 依赖锚定；报告 RMSE 劣势与失败风场 | 已有，需补 RMSE 处理（§5 A2） |

**风险**
- 方法本身的性能优势小（MAE 1.2%，RMSE 更差），期刊定位应偏向“机理分析 + 实证”，而非“新 SOTA 模型”。
- 负结果需要写清楚适用条件：Pangu 0.25°、1 h、单站一年数据、独立训练。

## 5. 还需要补的实验

### P0（决定能否成文）

**A1. 可加融合对照（“作用方式”的直接检验）**
- 构造 ADD 模型：`y = o + f(历史) + g(天气)`。两条支路完全独立，没有交互；参数量与 W0 匹配。
- 对比 W0（状态条件化）。共享设定下的 canonical J−A 曾有 3.4% 的差距；独立设定还没有做。
- 2×2 交互（H2）只说明“历史状态改变天气的作用”。A1 证明这种交互需要在模型结构中显式建模，二者缺一不可。
- 规模：56 × 5 = 280。

**A2. RMSE 劣势处理**
- W0 与 Transformer/TiDE 统一换损失（MSE 或 MAE+MSE），或在 2023 上选 Huber δ。三个模型同样处理，各 56 × 5。
- 目的：确认 RMSE 劣势来自损失函数（MAE 训练使预测偏中位数），而不是模型结构。
- 若无法消除，论文必须同时报告 MAE 和 RMSE，并在讨论中说明。

**A3. 历史交换干预（无需训练）**
- 对 W0 做与天气错排相同规则的历史错排（同月、同 phase、不同日），天气保持原样。
- 按时效报告误差变化，补充 H2 的“固定历史”对照：H2 改了训练过程，历史错排只改评价输入。
