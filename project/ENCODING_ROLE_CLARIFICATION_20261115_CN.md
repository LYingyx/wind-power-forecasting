# 编码角色与公平对照说明

用户最新约束：**不把天气编码作为机制贡献点或独立贡献点。** 此约束取代此前结果报告中围绕“简化天气映射”组织贡献的建议。编码结果及性能原值不变；本次不启动额外训练。

## E2L具体是什么

E2L是项目内部实验编号，L表示linear。当前选定width64，天气支路为：

`标准化14通道天气 → Linear(14,64) → Linear(64,64) → Linear(64,64)`

中间没有GELU等非线性激活，三层带偏置线性层合起来仍是一个仿射映射`z = Wx + b`。多层参数化会影响优化、权重衰减和训练轨迹，但不扩大这一支路的仿射函数集合。整个预测模型仍有非线性历史编码器、解码器等部分，不能称为线性预测模型。实现见 [当前模型定义](runs/daily_ablation_restart_20261114_v1/code/model.py:54) 和 [天气输入选择](runs/daily_ablation_restart_20261114_v1/code/model.py:119)。

因此，E2L不是原来的复杂柱坐标编码，也不是新提出的机制；它最初是控制“多层参数化”和“非线性激活”影响的对照版本。

## 已经做过哪些编码对照

|编号|天气支路输入|映射|主要回答的问题|
|---|---|---|---|
|E0|原始14通道|单层线性|基本天气投影|
|E1|原始14通道＋地形高度|单层线性|天气支路直接提供地形高度的影响|
|E2L|原始14通道|三层线性，无激活|多层线性参数化|
|E2N|原始14通道|三层MLP，含GELU|对E2L，严格同参数量检验非线性|
|E2|原始14通道＋地形高度|三层MLP，含GELU|对E1检验非线性参数化；对E2N检验天气支路高度输入|
|E2C|15维柱坐标表示|与E2相同形状的MLP|同参数量比较原始坐标与柱坐标|
|E3|柱坐标分三组|分组MLP再融合|分组编码；不严格等参数量|

E2C将近地、低层、层间差分等组成15维表示，可由原始14天气变量和地形高度恢复；它没有新增观测天气信息。所有当前模型的站点静态支路本身已有地形高度，所以E1/E2并不是首次向整个模型引入地形信息。E2C改动也包含相应训练期归一化，现有比较不把坐标变换和归一化分离。

上述7种版本都在无轨迹条件与CBH两种背景下，以5个seed、同一55站共享训练评估；E2C复用本轮已经重训的W0_R3/M2_CBH。它们是**同一框架内部的编码对照**，不是7个独立外部baseline。各编码沿用对应W0的已选超参数，没有逐编码另做等预算搜索，所以结论限定于当前训练设置。

结果没有支持“复杂编码一定更好”：无条件下E2L比E2C的MAE/RMSE低0.275%/0.442%；原始天气＋高度的E2也比E2C低0.121%/0.141%。CBH背景部分排序变化，不能把无条件下E2L胜出直接推广到所有背景。

## 现有对照还缺什么

当前TF_R3使用原始天气的线性投影加时效特征；它获得相同原始信息、SEL与区域观测，但没有挂接完全相同的E2C/E2L天气模块。TiDE/TFT也没有做这一模块互换。

“本模型内部替换编码”可以检验该组件在本模型中的作用；“本模型与标准TF”可以比较端到端预测性能。两者都不能单独回答“优势来自本模型核心结构，还是来自天气前端”。

如果保留复杂E2C，应补充最小的骨干×编码交叉对照：

|骨干|共同简单天气前端|共同E2C复杂天气前端|
|---|---|---|
|本模型|重新明确共同接入方式|本模型＋E2C|
|Transformer|相同前端，保留各自必要时效接口|Transformer＋同一个E2C|

如果最终选用E2L，同样补TF＋E2L。两边使用同一预报、历史功率、SEL/区域观测、站点信息、划分与种子，并控制新增模块及调参预算；时间特征应走明确分开的公共接口，避免把删掉TF时效特征误当作编码替换。保持编码相同的行间比较回答骨干差异，同一骨干内的列间比较回答编码增益。比较数值而不是强求模块必须提升。

该矩阵是待补的公平性对照，不是已完成实验。无需仅为了对照数量增加更多编码名称。

## 如何定位贡献

编码保留为模型实现选择及消融项，是否采用由性能、稳定性和计算成本决定；正文无需把它列为独立创新。

研究主张应围绕完整单风场预测框架，以及在相同信息和合理训练预算下对强baseline的稳定优势。若要声称某个核心机制有效，需在固定编码后单独移除、替换或错配该机制；当前CB/CBH和RM结果还不支持将其直接写为已经成立的机制贡献，历史×天气交互也不是W0独占的现象。

不能因为编码不作为贡献，就自动把CBH、物理特征或交互分析改名为三个新机制。后续路线先解决完整模型的公平性能优势和真正机制的可识别增益；在此之前，不预设三个已成立的正向贡献。
