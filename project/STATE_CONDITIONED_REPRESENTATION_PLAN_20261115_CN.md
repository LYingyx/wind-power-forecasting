# 状态条件 15 min 中间表示的检验方案（含 RMSE 提升）

日期：2026-11-15。协议：每日 00 UTC 起报、起报后 15 h 可用；0–6 h、15 min 分辨率；55 站共享训练；2022 训练、2023 选择。

## 0. 先确认的事实（零训练）

使用 W0_R3 / TF_R3 共享模型在 2023 年的预测，5 seeds 平均。同一时效段内，按目标时刻落在整点或 :15 / :30 / :45 比较 MSE：

| 时效段 | W0：:15 / :30 / :45 相对 :00 | 同一时刻难度 E[(y − h)²] 相对 :00 |
|---|---|---|
| 0–1 h | +0.62% / +0.52% / +0.02% | +0.62% / +0.62% / +0.19% |
| 1–3 h | −0.12% / −0.09% / −0.29% | −0.04% / −0.08% / −0.12% |
| 3–6 h | −0.32% / −0.22% / −0.20% | −0.15% / −0.12% / −0.04% |

TF 的模式相同。

**含义**
- 线性插值在小时内部没有造成可见的损失，误差主要在小时尺度上：爬坡何时开始、幅度多大、是否发生。
- 因此"15 min 中间表示"的价值不可能来自补出小时内部的细节，只可能来自**按当前状态重新组织小时尺度的变化**，也就是时机与幅度。
- 检验要以此为判据：新表示的收益若只出现在非整点目标上，就是噪声。

## 1. 模块定义

宿主骨干：当前最好的 W0 共享版本（R3 输入、E2L 天气映射）。只替换"天气 → 解码器查询"这一段，其余结构与训练设置都不变。

1. **小时潜表示**：8 个小时节点（同一次起报），经共享天气编码 φ 得到小时潜 token z_0 … z_7。
2. **状态 c**（只用起点前可得的信息）：
   - 历史编码器的汇总；
   - 当前功率；
   - 可变化空间：1 − 当前功率，以及当前功率本身；
   - SEL-STATE；
   - 三环区域摘要。
3. **15 min 潜表示**：u_k = lerp(z)(t_k) + Δ_k，k = 1 … 24。
   - t_k 是目标时刻相对节点的真实偏移；
   - Δ 的输出层零初始化，初始时等于"在潜空间中线性插值"；
   - u_k 替代原来的"插值后天气编码"，作为解码器查询的天气部分。

## 2. 变体（每组 5 seeds，共享训练）

| 编号 | Δ 的来源 | 回答的问题 |
|---|---|---|
| R0 | 现有模型：先在天气空间插值，再编码（已有结果，不重训） | 参照 |
| R1 | Δ = 0：先编码，再在潜空间插值 | 插值放在哪一侧本身是否有影响（无新参数） |
| R2 | 确定性 Δ = g(z 窗口, t_k)，不含状态 | 潜空间细化本身（相当于旧 DET 搬到表示空间） |
| R3 | 确定性 Δ = g(z 窗口, t_k, c) | 状态条件是否有用（确定性版本） |
| **R4** | **生成式**：Δ ~ p(Δ \| z, t_k, c)，用条件流匹配建模；推理时采样 K = 8 次 | 主方案 |
| R4-noS | R4 去掉 c | 生成式本身的作用 |
| R4-wrongS | R4，但 c 换成同月同钟点另一日的状态（训练与评价都换） | 排除"只是多了参数和随机性" |

**R4 的训练目标**：表示空间没有真值，用一个只在训练时使用的教师来定义"对 15 min 功率有用的表示"。
- **教师编码器**：读取已实现的未来 24 点功率与小时潜 token，输出低维 Δ\*（每个 token 4 维）；加噪声与 KL 约束，防止直接把目标抄过去。
  - 教师路径的损失：解码器(lerp + Δ\*) 对 y 的 MAE。
- **学生**：用条件流匹配学习 p(Δ\* | z, t, c)。
  - 学生路径的损失：用学生采样的 Δ 经解码器后的功率 MAE（采样器可微，联合训练）。
- **总损失**：教师路径 MAE + 学生路径 MAE + 流匹配损失（权重预先固定为 1 : 1 : 0.1）。
- **推理**：只用学生，不用教师。点预测 = K 个样本功率输出的均值（预先写定）；样本中位数一并报告，但不参与选择。

**规模**：R1–R4 加两个对照，共 6 组 × 5 seeds = 30 次共享训练。R4 通过后再加 TF + R4（5 次），检验模块是否依赖骨干。

## 3. 判定（预先写定）

- **主判定**：R4 相对 R0 与同输入 TF_R3，MAE 和 RMSE 都改善 ≥ 0.1%，各自过半风场改善；高功率 RMSE 退化 ≤ 0.1%。
- **机制判定**：R4 相对 R3、R4-noS、R4-wrongS，MAE 和 RMSE 都改善 ≥ 0.1%。
  - 只胜 R4-noS：说明状态条件有用，但生成式不必要，改用 R3；
  - 只胜 R3：说明生成式有用，但需要说明状态的作用。
- **必报诊断**：
  - 分时效段结果；
  - 第 0 节的整点 / 非整点误差表（收益若只出现在非整点，视为无效）；
  - 大变化样本的 ΔMSE；
  - 爬坡起始时刻误差。
- **全部不通过**：在论文中如实写明"以状态为条件的生成式时间对齐，在本数据下没有超过线性插值"，主模型保留线性插值。

## 4. 提升 RMSE 的做法（与上面同一批次，不单独讨论大变化）

RMSE 上不去的根源：MAE 训练得到条件中位数，残差右偏（3–6 h 的均值减中位数约 +0.01）；在变化时机不确定时，模型统一收缩。RMSE 需要的是条件均值。按优先级：

1. **R4 的多样本均值**：对时机不确定性采样后取平均，相当于在变化时机上求条件均值。RMSE 应直接受益，MAE 是否受损由主判定检验。这是方法自身的一部分，不另加组件。
2. **损失 MAE + λ·MSE**，λ ∈ {0.1, 0.3}：只加在最终候选上，同时以同样方式加到 TF\* 上（4 组 × 5 seeds）。按 2023 年"两个指标都不劣于 MAE 训练"选择 λ；不通过就保持纯 MAE。旧协议下的单站独立训练中这一做法失败过，这里只作一次复核。
3. **种子集成**：5-seed 平均使两个模型的 MAE 和 RMSE 都下降约 1.6%，但两边同样受益，不改变排序，也不是方法贡献。最终主表可以同时报告单模型与集成两种口径，集成时 baseline 也必须集成。

## 5. 执行顺序

1. R1、R2、R3（15 次训练，确定性，实现简单）与 R4 的实现、冒烟测试并行。冒烟测试需核对：教师只在训练时使用；采样器可微；Δ 初始为 0 时输出与 R1 一致。
2. R4、R4-noS、R4-wrongS（15 次训练）。
3. 通过后：TF + R4；损失 λ 复核；扩到 10 seeds；冻结后做 2024 探索性复评。
