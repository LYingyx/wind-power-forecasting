# 新方向：以风场群实时功率为观测、再分析级天气为特权监督的业务天气校正

日期：2026-11-01。状态：方向提案，尚未验证。先做零训练诊断与上限实验，再决定是否投入。

## 1. 为什么换这个方向

- **已排除的方向**：融合算子类的改进（门控、FiLM、注意力变体、状态灵敏度乘法）与交叉注意力本质相同，文献也多，不再作为机制。
- **业务场景的核心矛盾**：NWP 年龄为 12–23.75 h，但本站与周边风场的实时功率包含“此刻真实天气”的信息。现有模型只能从功率损失中间接学习“业务预报错了多少”，单站一年数据下这种学习信号很弱：显式残差和误差记忆都没有增量。
- **剩余误差的位置**：3–6 h、中等功率区间、冬夏季。这里正是天气误差主导、功率曲线最陡的区段。
- **统计学根源（errors-in-variables / regression dilution）**：输入天气带噪声时，学到的“天气 → 功率”响应会被系统性压扁。模型对天气变化反应不足，在陡峭区段和爬坡中尤其损害 RMSE。已有文献在功率曲线场景确认了这一效应（GEFCom2012 上的 regression dilution 研究）。降低输入天气的误差，比在融合结构上做文章更直接。

## 2. 机制设计

**训练时可用、推理时不可用的“特权信息”**：再分析级的近真实天气。可以是 ERA5 本身，也可以用现有 ERA5 初始场 Pangu 的 1 h 预报作代理（现有数据中逐小时可得）。它只作为训练目标，推理时不使用。

**机制一：观测驱动的天气状态校正（learned assimilation）**
- 输入：业务 NWP 轨迹，以及本站与三距离环周边风场的实时功率（视为分布式“风速观测”）。
- 输出：目标风场各预测时刻的校正后天气（10 m 风速、风矢量、SEL 物理量），以及校正不确定度。
- 训练：
  - 辅助损失：校正天气对近真实天气的误差；
  - 主损失：功率损失，端到端联合训练。
- 推理：只需业务 NWP 与已观测功率，部署可行。

**机制二：校正后天气驱动的功率响应**
- 功率预测由校正后天气驱动，状态上下文保持现有结构。
- 可选：校正不确定度作为输入，在校正可信时允许更陡的响应、不可信时收敛。这一项属于不确定度感知输入，需单独消融，不预设为贡献。

**与交叉注意力、门控的区别**
- 改变的是学习信号（特权监督）和中间表示（物理意义明确、可单独检验的天气状态），不是融合算子。
- 可单独评价“校正后天气比业务 NWP 更接近真实天气”，按时效、按风速段画出校正收益。这是交叉注意力无法提供的可检验中间量。
- 把现有“区域实况补充”从“多加特征”提升为“风场群作为观测网，校正区域天气状态”，与原贡献二衔接。

## 3. 与已有工作的关系（初步检索，尚需系统核查）

- 以 ERA5 为标签校正 NWP 风场：已有（如 MOS 类、西北太平洋 10 m 风 DL 校正）。**不新**。
- 在 ERA5 上训练、以业务 AI 预报为输入预测风电（Hardy & Finney 2025）：已有，但不使用实时功率观测。
- 把风机风速计或机舱雷达同化进物理 NWP（Haupt 等 2017；机舱雷达 2024）：已有，但属于物理同化，不是学习式，也不以功率为观测。
- 检索中**未发现**：以风场群实时功率为观测、再分析级天气为特权监督、端到端学习业务 AI-NWP 校正并用于 0–6 h 单站功率预测的工作。新意风险：**中**，需系统核查后确认。

## 4. 先做的诊断（决定是否投入）

**D1 数据可行性（零训练）**
- 确认近真实天气来源（ERA5 或 ERA5 初始场 Pangu 1 h 预报）在 2022–2024、56 站位置可用，且与业务 NWP 的时间对齐无泄漏。

**D2 天气误差的可校正空间（零训练）**
- 业务 NWP 10 m 风速对近真实风速的误差，按时效、年龄、季节、风速段统计。
- 起报时刻的天气误差，与 +1…6 h 天气误差的相关（误差持续性）。
- 由本站与周边风场功率反演的等效风速（只用非平台区间）与业务 NWP 之差，能解释多少起报时及未来时刻的天气误差（按时效的 R²，2022 拟合、2023 评价）。

**D3 上限实验（少量训练，56 站 × 2 seeds，只用 2023）**
- W0/TF* + SEL + 区域实况，把业务天气替换为近真实天气（不可部署）：给出“天气完全校正”时 MAE 与 RMSE 的最大改善。
- 判定：
  - 上限小于 3%：方向不值得投入；
  - D2 显示 3–6 h 的可解释比例接近 0：机制一预计无效，需重新考虑。

## 5. 训练实验（D1–D3 通过后；2023，56 站 × 5 seeds，W0 与 TF* 两个骨干）

| 编号 | 变体 | 回答的问题 |
|---|---|---|
| P0 | 现有最终模型（SEL + 区域实况） | 对照 |
| P1 | + 天气校正模块，特权监督 + 功率损失 | 主方案 |
| P2 | P1 同结构同参数，**无辅助监督** | 特权监督是否必要 |
| P3 | P1，但校正模块不读取功率观测（纯 NWP → 近真实，即 MOS） | 实时观测是否必要 |
| P4 | P1，功率观测换为同月异日 | 负对照 |
| P5 | P1 + 校正不确定度输入 | 可选：响应是否需要不确定度感知 |

**判定**
- P1 相对 P0 与 P2：MAE 与 RMSE 均改善 ≥ 0.1%，各过半风场改善；
- P1 优于 P3、P4；
- 校正天气在独立年份上确实更接近近真实天气，按时效报告。

**后续**：通过后冻结、10 seeds；2024 为探索性复评；最好用 2025 做独立确认。

## 6. 风险

- 显式残差、误差记忆此前无效，说明“功率观测中的天气误差信息”可能有限；D2 是关键门槛。
- 近真实天气的质量本身有限（ERA5 有偏差，1 h Pangu 预报不是观测）；校正目标的误差会传导。
- 若上限实验显示天气误差不是剩余误差的主导，本方向应放弃。
